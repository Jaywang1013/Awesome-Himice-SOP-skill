# 公开仓库安全边界

本仓库公开的目的，是让已获授权的同事和合作开发者发现、克隆和部署通用流程；不代表客户资料、模板实例或凭据可以公开。

禁止提交：

- 客户名称、税号、合同、报价、预算、发票、支付截图、录音和转写原文；
- 员工电话、身份证件、个人账户、内部通讯录和默认信息的本地版本；
- API Key、Webhook、Client Secret、OAuth Token、Cookie、`.env` 和运行日志；
- 第三方项目的源码、二进制、模型权重或受限制内容，除非已取得书面许可。

允许提交：

- 空白模板、脱敏示例、通用业务规则和可复现的验证说明；
- 指向上游项目的链接、安装前置条件和许可证提示；
- 不含业务数据的 Skill、脚本和平台接口定义。

在修改仓库可见性、添加外部集成或启用云端模型前，先检查该变更是否会扩大资料的可访问范围。对客户名称、税号、发票和录音，默认采取本地处理与禁止云端上传策略。
