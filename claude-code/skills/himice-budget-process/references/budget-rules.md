# Himice 预算表规则

## 表头

| 信息 | 主表位置 |
| --- | --- |
| 会议名称 | `B2` |
| 执行时间 | `B3` |
| 会议人数 | `G3` |
| 会议负责人 | `G4` |
| 会议报账人 | `G5` |
| 公司参与人数 | 人员参与说明区域 |

## 映射优先级

1. 客户已确认报价、供应商成本、合同和正确项目预算样例。
2. 公司本项目模板的固定结构与格式。
3. 公司默认标准。

客户文件的明确费用、费率或成本优先于默认值；默认值只填补缺失信息，并在交付时标注。

## 代付五项

| 专用类别 | 典型来源关键词 | 计入服务费 |
| --- | --- | --- |
| 会场租赁 | 酒店会场、场地租赁、会议室 | 是 |
| 酒店住宿 | 酒店住宿、房费 | 是 |
| 酒店餐饮 | 酒店餐饮、正餐 | 是 |
| 机票 | 机票、航空 | 是 |
| 动车 | 动车、高铁、铁路 | 是 |
| 茶歇 | 茶歇、coffee break | 否 |

代付服务费 = 五项专用类别收入小计之和 × 已确认费率。无明确费率时用 6%；报价明确写 5% 等费率时使用报价费率，并不得重复收取。

## 成本与现金

- 预计成本应优先采用供应商报价；仅在缺少供应商报价时镜像预计收入。
- 需提取现金的物料只对其 J 列预计成本单项小计使用黄色 `#FFC000`；其他单元格保持模板原格式。
- 任何插行、删行或移动都要重新核对小计、总计、服务费和税费公式范围。

## 默认操作费用

餐饮 ¥70/人/天；交通 ¥1,000/人、次数 2；住宿 ¥300/间/晚、两人一间；正式员工人补 ¥120/人/天；试用期/实习生 ¥70/人/天；M 级 ¥0。B1–B6 为项目助理/项目专员。
