# 基线质量摘要

本报告基于 `全量企业名录_15050条.csv` 的只读扫描生成，统计时间为 2026-08-25。它描述数据可如何使用，不把目录统计解释为市场份额、供应商排名或资格结论。

## 规模与完整性

| 指标 | 值 |
| --- | ---: |
| 记录数 | 15,050 |
| 字段数 | 37 |
| `company_id` / `company_name` / `unit_type` / `industry_chain_position` / `service_scope` / `data_source_summary` / `trust_level` / `verification_status` / `confidence` 空值 | 0 |
| 官网空值 | 14,879 |
| 地址空值 | 9,906 |
| 电话空值 | 12,099 |
| 邮箱空值 | 12,911 |

联系方式和官网空值较多，因此不得把“无联系方式”推定为企业不存在，也不能只按可联系电话筛选供应商。
