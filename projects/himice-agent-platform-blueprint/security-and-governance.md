# 安全与治理

## 数据分类

| 等级 | 示例 | 默认处理 |
| --- | --- | --- |
| public | 官网公开内容、公开活动资料 | 可使用获批外部服务 |
| internal | 通用 SOP、空白模板、内部术语 | 仅公司账号与授权设备 |
| confidential | 客户报价、预算、合同、会议录音 | 默认本地；云端需授权 |
| restricted | 税号、联系人、发票、支付截图、人员信息 | 本地处理；默认禁止上传和回传 |

数据等级继承输入中的最高等级。输出不得因为内容经过模型整理而降低等级。

## 身份与权限

- 钉钉以实际员工 OAuth/企业应用身份执行，不使用共享个人账号。
- 机器人配置用户、群、部门和 Skill 白名单；默认拒绝未知来源。
- 组织数据访问遵循最小权限，定期回收离职人员和不再使用的应用授权。
- API Key、Client Secret、Webhook、OAuth Token 和本地客户默认文件不得进入 Git。
- 生产机器人不得使用个人会员或个人 API Key 作为全公司共享凭据。

## 审计

记录：请求 ID、员工身份标识、Skill/模板版本、时间、状态、外部写入目标、确认事件、输出文件哈希和错误类别。

默认不记录：附件正文、税号、联系方式、完整发票内容、录音正文、模型密钥和 OAuth Token。若合规要求记录正文，需单独确定加密、访问、留存和删除政策。

## 人工确认

以下操作必须在执行前确认：

- 上传或共享文件；
- 向群或个人发送包含业务数据的消息；
- 创建、提交或修改审批、待办、表单；
- 修改钉钉文档、通讯录、权限或组织数据；
- 把 confidential/restricted 数据发送到外部模型或知识库；
- 更改部门默认信息或公司业务规则。

## 模型与供应商

上线前记录模型供应商、部署地域、是否用于训练、保留期限、删除机制、子处理方、费用、限流和事故通知方式。会员权益、API 套餐和企业开放平台授权分别建档，不以品牌相同推定权限互通。

## 发布门禁

新 Skill 或新渠道适配器进入试点前必须完成：

1. 使用虚构/脱敏数据的成功与失败测试；
2. 必填信息、文件格式、金额/公式和输出路径核验；
3. 未授权用户、越权文件、重复请求和取消测试；
4. 云端传输与外部写入确认测试；
5. 断网、超时和第三方失败后的安全停止与重试边界；
6. 许可证、数据条款和管理员权限复核；
7. 可回滚到本地 Skills 的操作说明。
