# Himice Notification And Approval — Codex

只使用当前环境已安装并获授权的 Codex Connector。通知不等于财务、合同或管理审批；除非目标系统返回正式审批记录，否则只能标记为“已通知”或“已收到回复”。

1. 发送前确认渠道、收件人/群组、项目、消息正文、附件、期望动作与截止时间；无法唯一识别对象时先停止。
2. 若用户已明确要求发送且内容/目标完整，可直接执行；内容含客户资料、金额、手机号或附件时，再核对授权范围。
3. 发起审批时写清事项、金额/版本、审批人、截止时间和可接受操作；不得代替审批人做决定。
4. 发送后回读消息 ID、时间和渠道状态；审批只记录目标系统明确返回的状态，不从“收到”“好的”等回复推断批准。
5. 失败最多重试一次非破坏性请求；仍失败时保留草稿并报告原因，避免重复通知。
