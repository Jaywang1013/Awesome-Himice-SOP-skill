# Himice Enterprise Knowledge — Codex

优先使用对应的 Notion、Google Drive 或 SharePoint Connector/Plugin。不同系统的权限与版本独立，不能因为一个连接可用就假定另一个也可用。

1. 先确认问题范围、部门/项目、时间和允许检索的知识源；使用站点、数据库、文件夹或项目标识缩小范围。
2. 读取标题、路径/URL、所有者、更新时间和正文后再总结；同名文件优先最新正式版本，但保留版本差异。
3. 跨来源结论逐条标注来自 Notion、Drive 或 SharePoint，不把推断写成公司制度；冲突时列出来源和日期并标待确认。
4. 创建、覆盖、移动、共享或修改权限前，确认目标对象和授权；写入后回读验证。
5. 只返回用户有权访问的内容；不得把客户资料复制到权限更宽的知识库。
