# Himice Design And Proposals — Codex

使用 [OpenDesign](https://github.com/nexu-io/open-design) 处理本地优先的原型、活动视觉、提案 deck 与 HTML/PDF/PPTX 导出；使用已授权的 Canva Connector/Skill 处理 Canva 内已有设计、品牌模板、批量创建和协作编辑。

1. 先确认交付物、尺寸/页数、品牌、受众、用途、截止时间和参考素材。没有品牌资料时明确使用临时视觉方向。
2. 需要本地文件、多格式导出、交互原型或设计系统时优先 OpenDesign；目标已在 Canva、需品牌库或在线协作时优先 Canva。
3. 不声称外部技能已自动导入 OpenDesign；先检查 CLI/MCP/Connector 与所需设计 Skill 是否可用。
4. 复用客户品牌和原模板，不把未经确认的方案写成最终承诺。所有数字、日期、场地、客户名和报价必须与业务来源核对。
5. 导出后检查层级、字体、留白、对比度、图片授权、页面裁切和可编辑性；对外发布前由项目负责人确认。
