# Himice Notification And Approval — Claude Code

只使用当前会话实际配置并获授权的 MCP/Connector。通知不等于正式审批；只有目标系统明确返回审批记录时，才能标记批准或拒绝。

1. 发送前确认渠道、收件人/群、项目、正文、附件、期望动作和截止时间；对象无法唯一识别时先停止。
2. 消息含客户资料、金额、手机号或内部文件时，核对最小披露范围与目标权限。
3. 发起审批时写清事项、版本/金额、审批人、截止时间和可选动作，不代替审批人作决定。
4. 发送后回读消息 ID、渠道和时间；普通“收到”“好的”等回复不得推断为批准。
5. 失败只做一次安全重试，仍失败时保留草稿并报告，避免重复通知。
