# Himice Operation Expense Reimbursement（DSH）

读取 `references/operation-expense-rules.md`。本 Skill 只整理报销资料和预算差异，不替代财务审批、税务判断或付款操作。

## 输入

确认项目/会议名称、对应预算表、报销人、报账人、会议负责人、每笔实际支出（日期、类别、金额、用途、支付人）、可用的发票/收据/支付凭证，以及实际人数、天数、住宿晚数和人员结构。缺少公司报销单模板时，输出可复核的报销明细、差异和待补资料清单，不虚构财务审批单。

## 处理

1. 每笔实际支出映射到预算项目，记录预算金额、实际金额、差异、差异原因和资料状态；同一支出只能保留一个付款/报销路径。
2. 按参考规则将餐饮、交通、住宿和人员补助与实际对比。标准仅作预算/差异核对依据，未经制度或项目审批确认，不能当作报销上限或审批结论。
3. M 级管理层不计人补；B1–B6 是项目助理/项目专员。身份、人数、天数或住宿晚数不清楚时标为 `[待确认]`。
4. 不把会议服务商代付、预算黄色现金标记或客户报价自动计为个人可报销支出；检查其是否与供应商付款或其他报销重复。

## 输出

每条报销明细至少列出：费用类别、发生日期、用途、实际金额、预算对应项/预算金额、差异、支付/报销人、凭证状态、待确认项。总额必须能由明细复算，原始凭证金额不得改写。

审批链、发票/税务口径、报销时限、账户、报销单字段与超标准处理一律列为 `[待财务确认]`，直到公司正式补充制度。
