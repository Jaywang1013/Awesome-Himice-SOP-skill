# Himice Budget Process（DSH）

先读取 `references/budget-rules.md`，使用 `assets/【项目预算表】鱼鹰号+活动名称.xlsx` 作为空白模板；客户或项目提供的更新模板优先。处理 Excel 时优先使用已安装的 OfficeCLI，并在改动后校验及渲染主表。

## 必填输入

开始前确认：会议名称、会议人数、执行开始/结束时间、公司参与人数、会议负责人、会议报账人。写入 `B2`、`B3`、`G3`、`G4`、`G5` 和模板人员说明区。缺少这些信息时先询问，不得臆造。

## 执行流程

1. 提取客户报价中的板块、明细、规格、单价、数量、次数、小计、供应商成本及“会议服务商代付”标记，先复算报价总计。
2. 将标明代付的酒店会场、酒店住宿、酒店餐饮、机票和动车映射到模板的五项专用行；茶歇不进代付服务费基数，且不得在普通板块重复计入。
3. 其余项目按客户报价顺序写入。连续同板块纵向合并第一列；插入或删除明细行时复制相邻格式和公式，并同步更新小计与总计。
4. 预计成本优先用供应商成本；缺失时才临时镜像预计收入并标为待采购核价。黄色只用于需提取现金物料的预计成本总价单元格。
5. 按参考规则填默认操作费用。客户明确的代付费率或金额优先；未明确时才使用公司默认 6%。

## 验收

逐项检查“单价×数量×次数”、板块小计、五项代付基数、服务费、税费、预计收入、预计成本与毛利。扫描公式错误，渲染检查表头、第一列合并、黄色现金总价和人民币两位小数格式。交付时说明镜像成本、代付费率来源及待确认输入。
