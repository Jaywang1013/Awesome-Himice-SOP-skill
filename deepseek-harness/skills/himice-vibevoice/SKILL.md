# Himice VibeVoice（DSH）

使用 [VibeVoice-ASR](https://github.com/microsoft/VibeVoice) 的语音转文字能力处理会议音频。它支持长音频、说话人、时间戳与自定义热词；本 Skill 不包含模型或上游代码。来源说明见 `references/sources.md`。

## 开始前

先确认录音已获参会者和客户授权。收集会议/活动名称、客户或主办方、日期地点、参会角色或名单、语言/方言、输出要求与重点术语。读取 `references/meeting-glossary.md`，并从本项目材料补充客户名、姓名、供应商、场地、品牌与缩写作为热词。

## 转写与纪要

1. 使用已批准的上游 ASR 部署生成保留说话人和时间戳的原始转写；超出支持长度时按自然议题边界切分并保持连续时间基准。
2. 对照音频校验姓名、数字、金额、日期、地点、项目编号与责任人；听不清时标记 `[待确认]`，不得猜测。
3. 将“原始转写”和“整理后纪要”分开交付。纪要包含背景、关键结论、决定事项、行动项、风险/待确认项。
4. 行动项表使用“事项、负责人、截止时间、来源时间戳、状态”；音频未给出负责人或日期时填 `[待确认]`。

会展语境中应区分会前策划、搭建、彩排、开展、现场执行、撤场和复盘，不能把讨论方案当作确认执行项。金额、交期、责任、合同承诺和对外内容必须人工复核；不得使用本 Skill 合成、克隆、伪造或冒充声音。
