# Himice Advance Fund Application Process（DSH）

读取 `references/advance-fund-rules.md`，默认使用 `assets/【预估协作人审批表模板】鱼鹰号+活动名称.xlsx`。本 Skill 只生成表格，不替代审批、付款或税务判断。

## 本地优先与隐私

客户名称、纳税人识别号、联系人、个人姓名和原始预算表只能在用户本机处理及保存。不得用网页、API、云盘、外部服务或 GitHub 上传；不得将真实客户资料写入 Skill、README、样例、日志或提交信息。仓库只保留空白模板和通用规则。

## 强制默认信息确认

在读取预算表或修改审批表前，先检查 `references/department-defaults.local.md`；没有时提示用户从 `references/department-defaults.example.md` 复制并仅在本地补全。每次调用都必须先展示：

> 这是 `<部门>` 的默认信息。是否使用该默认信息？若有修改请修改后提交给我；若想更改默认信息，请按格式修改。
>
> 1. 使用默认信息，继续执行
> 2. 有修改，根据用户给到的信息继续执行
> 3. 更改默认信息，按用户给到的新默认信息执行并更改本地默认信息

选择 1 使用完整本地默认配置；选择 2 用用户本次信息覆盖本地底稿且不修改本地文件；选择 3 校验完整格式后仅更新本机 `department-defaults.local.md` 并用于本次表格。确认前不得填表；本地文件缺失或含占位符时，不可选 1，应补全或选择 2。不得将个人信息写回 Skill 或 GitHub。

## 处理

1. 从预算表提取会议名称、会议报账人、日程、会议人数、预计收入总计、预计毛利率、预计毛利；收集用户提供的客户名称和税号。
2. 仅填写审批表第 4 行，保留格式、下拉、备注和工作表结构。
3. 填入项目名称、报账人、营业额、毛利率；毛利润必须用 `营业额×毛利率` 公式。金额两位小数，毛利率两位百分比。
4. 填入可确认的活动日期、内容、地点和人数；活动类型、业务类型、竞标状态、本地客户、联系人、客户来源/类型、人员比例按已确认的本地默认信息或本次修改填写；其余无来源字段清空示例值或写 `[待确认]`，不得猜测。
5. 写入客户名称和税号，但只保存于用户本地输入/输出工作簿。核验营业额、毛利率、毛利润和预算表一致，并检查公式与版式。

## 输出

输出本地生成的审批表，并只说明已填字段和待确认字段；不要在说明中复述客户名称、税号或其他敏感资料。
