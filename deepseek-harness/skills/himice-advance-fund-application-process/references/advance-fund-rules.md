# Himice 预估协作人审批表（备用金申请表）规则

## 字段映射

| 审批表字段 | 预算表来源 | 规则 |
| --- | --- | --- |
| 鱼鹰项目名称（含编号） | 会议名称 | 原样填写 |
| 报账人 | 会议报账人 | 缺失写 `[待确认]` |
| 营业额（估） | 预计收入总计 | 显示两位小数 |
| 毛利率（估） | 预计毛利率 | 显示 `0.00%` |
| 毛利润（估） | 营业额 × 毛利率 | 使用公式 |
| 活动开始/结束 | 日程安排 | 使用真实日期 |
| 活动内容、地点、人数 | 预算表的明确内容 | 无法确认写 `[待确认]` |
| 客户名称、纳税人识别号 | 用户明确提供 | 仅本地输入与输出 |

## 必须留空或标待确认的字段

竞标状态、本地客户、业务类型、客户联系人、第二客户信息、客户来源、客户类型、销售/谈判/执行人及比例没有明确来源时，清空模板示例值或写 `[待确认]`；不得猜测。

## 隐私规则

禁止将客户名称、税号、联系人或原始预算上传云端、网页、API、云盘或 GitHub；禁止把真实客户资料放入提交记录、Skill 文档、测试数据或日志。`assets/` 只保存空白模板，完整表仅保存在用户本地输出目录。
