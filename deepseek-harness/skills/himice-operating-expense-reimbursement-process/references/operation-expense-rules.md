# Himice 操作费用报销：单表录入规则

## 模板与填写边界

- 默认模板为 `assets/【模板】项目操作收支明细表.xlsx`，当前只有 `表1 (2)` 一张工作表（显示为“项目操作收支明细表”）。
- 只填写现有付款区和空白明细行；保留数据验证、金额格式、行/列格式、小计和资金汇总公式，不得增删或重排工作表。
- 每行填写序号、日期、类型、明细、摘要、单价、数量、次数、金额公式、发票、备注、经手人；金额为 `单价×数量×次数`。
- 支付截图是付款事实；只有实际发票文件才能在“发票”列选择 `√`。

## 票据、行程单与路线

- 同一交易的发票、支付凭证与行程单不得重复计费。
- 行程单有 N 笔行程时，必须生成 N 行；每行使用该行程的日期和金额，N 行之和必须与关联发票价税合计一致。
- 备注固定为 `滴滴：<出发地>-<目的地>`、`货拉拉：<出发地>-<目的地>`、或 `<平台>：<出发地>-<目的地>`。
- 共用一张发票的多条行程，每一行均在“发票”列勾选 `√`。

## 付款路径与费用映射

- 现金支出：微信/支付宝/零钱、项目备用金或个人垫付且有支付凭证。
- 刷卡支出：可确认的信用卡/银行卡刷卡；已转帐款项：银行转账证据；未付款：明确未付。路径不清楚标 `[待确认]`。
- 交通（客运、货运、机票、动车、加油）→ `操作费用/交通费`；餐食 → `操作费用/餐饮费`；印刷、花卉等 → `操作费用/物料费`；用途不充分的便利店等 → `操作费用/其他操作费`。
- 酒店、会场、餐饮、机票、动车的会议服务商代付或酒店签单，不自动纳入个人报销。

## 已确认的预算/差异核对标准

| 项目 | 标准 | 核对方式 |
| --- | ---: | --- |
| 餐饮费 | ¥70/人/天 | 公司参与人数 × 执行天数 |
| 交通费 | ¥1,000/人 | 公司参与人数 × 次数 2 |
| 住宿费 | ¥300/间/晚 | 向上取整（公司参与人数÷2）× 住宿晚数 |
| 正式员工人补 | ¥120/人/天 | 正式员工人数 × 执行天数 |
| 试用期/实习生人补 | ¥70/人/天 | 对应人数 × 执行天数 |
| M 级管理层人补 | ¥0 | 不计人补 |

B1–B6 为项目助理、项目专员。以上标准仅用于预算/差异核对；审批、税务、报销时限、账户和超标准处理均为 `[待财务确认]`。
