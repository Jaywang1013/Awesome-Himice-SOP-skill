# Himice 延展物料提示词 — 验收清单

- [ ] 只在用户提供活动主 KV 后输出延展提示词；未提供时说明需要图 1 与目标物料。
- [ ] 每项物料链接到实际存在的内置样机，并明确上传顺序为“图 1 新 KV、图 2 样机”。
- [ ] 所选样机与用户需求相符；不因“会务基础套装”擅自输出所有 23 项物料。
- [ ] 完整提示词要求移除样机可印刷面上的旧品牌和旧文字，保留物体结构、支架、手部、五金、材质、镜头及背景。
- [ ] 提示词按原样贴图、版式延展或品牌提取处理不同物料，不把整张 KV 机械压缩到小型或曲面物件。
- [ ] 未提供的姓名、日期、编号、二维码、箭头方向等字段标为待补，不虚构事实；明确文字和二维码需要后期校对。
- [ ] 输出强调结果仅为视觉预览，不能替代印刷源文件、尺寸确认和品牌审核。
- [ ] 未输出样机中的原活动名称、Logo、人员信息或其他既有画面作为新项目内容。
