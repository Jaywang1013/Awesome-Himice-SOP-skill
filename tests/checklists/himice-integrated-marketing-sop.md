# 整合营销验收清单

- [ ] 先读取现有 `himice-brand-context.md`，缺失时使用模板并明确资料缺口。
- [ ] 传播 Brief 只有一个业务目标和一个核心行动：获得活动方案咨询。
- [ ] 输出会前、现场、会后三阶段的内容成品、渠道、负责人、截止时间与衡量信号。
- [ ] 对外文案只使用已确认的主题、日期、城市、链接和服务范围；客户名称、人数、嘉宾与案例数据标为待确认。
- [ ] 渠道内容按官网、公众号、视频号和邮件分别设计，而不是机械复制同一文本。
- [ ] 竞品与效果结论标记为事实、观察或推断；没有数据时不编造 ROI、转化率或优胜结论。
- [ ] 预算、报销和媒体账户操作被明确排除或转交对应流程。
