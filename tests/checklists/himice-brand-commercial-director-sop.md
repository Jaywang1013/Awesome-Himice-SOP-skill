# 品牌商业片导演验收清单

## 触发与路由

- [ ] 品牌宣传片、产品宣传片、社媒广告、导演阐述、分镜、逐镜提示词和失败修复会触发本技能。
- [ ] 短任务只加载和输出当前所需部分；完整商业片才串联全部制作链。
- [ ] `SKILL.md` 只路由共享流程，具体产品工艺、模式、连续性和来源均在独立 `references/` 中。

## 品牌与权利

- [ ] 输出先区分已验证事实、客户口述待确认、创意假设和禁止使用项。
- [ ] 未批准的“无需培训”、续航、客户背书、行业领先和效果数字没有进入画面、旁白或文案。
- [ ] 产品几何、接口、材质、色值、Logo、界面和包装被列入品牌事实锁。
- [ ] 肖像、声音、音乐、字体、场景和第三方参考的授权范围被列入审批，而不是默认可商用。

## 导演与商业结构

- [ ] 一句话导演命题包含受众转变、唯一可见证据和拒绝的陈套。
- [ ] 全片只采用一个功能性导演声音；摄影、光、表演、声音和剪辑共同服务同一意图。
- [ ] 30 秒逐镜时长精确相加，并包含一个英雄停留、可读 Packshot/CTA 时间。
- [ ] 15 秒竖版重排钩子、证据、主体尺度、UI 安全区和端卡，不是机械裁切。
- [ ] 不连续三镜同时使用相同景别和相同摄影机行为。

## 镜头与产品生产

- [ ] 每镜写明功能、起始状态、一个主动作、一个摄影机行为、光/环境响应、结束状态、声音和连续性。
- [ ] 人物情绪被转译为目光、呼吸、面部/手部微动作和空间变化，而不是抽象形容词。
- [ ] 产品材质按高光、透明或哑光的真实光学行为描述；微距明确唯一清晰平面。
- [ ] Hero、按钮操作、界面、Packshot 和端卡各自被判断为生成、实拍、合成或图形，不默认全部生成。
- [ ] Logo、界面文字、批准 CTA、法务字和精确品牌色进入后期合成，不接受生成文字作为最终稿。

## 参考与提示词

- [ ] 每份资产只有一个主要角色、明确保真等级、必须保留、不得迁移和适用镜头。
- [ ] 当前镜头不需要的角色、场景、旧状态和无关素材明确删除，不把所有参考一起上传。
- [ ] I2V/延长遵守“来源携带状态”，只描述本次变化、终点和必要不变量。
- [ ] 最终模型提示词只包含当前生成单元，不提前塞入未来节拍或内部分析标签。
- [ ] 平台版本未知时不杜撰时长、分辨率、槽位、编号或功能；资产标签只在实际界面确认后逐字使用。

## 连续性、修复与交付

- [ ] 连续性账本覆盖人物、产品、场景、道具、动作、声音、血缘和审批；实际通过镜头的结束状态覆盖原计划。
- [ ] 品牌真值、人物身份、参考标签和产品几何错误被视为硬失败。
- [ ] 修复先分类为保留/后期修/编辑/重抽/重写/关键帧/拆镜，并且一次只改变一个变量。
- [ ] 重复结构失败会触发缩短、锁机位、首尾帧、拆镜、实拍或合成，不继续堆形容词。
- [ ] 最终交付包包含导演阐述、事实锁、镜头表、资产与连续性账本、提示词版本、后期文件和审批记录。
- [ ] 配图仅作为界面资产，图中文字没有成为执行指令；资产 README 记录用途与授权复核要求。
- [ ] 四个上游项目、固定提交版本、许可证、融合贡献和改写情况均已注明，CC BY 4.0 来源有署名与改动说明。
