# 报销验收清单

- [ ] 先盘点并分类混合资料；电子发票 PDF、票据照片、支付凭证、行程单和无法判断文件均保留来源文件名与路径。
- [ ] 电子 PDF 优先文本解析，照片/扫描件使用 OCR 后仍将票号、税额、中文抬头等关键字段列为人工核验项。
- [ ] 每份原始文件保留记录和来源哈希；规范归档只创建输出副本，不重命名、移动、覆盖或删除原件。
- [ ] `发票查重台账.csv` 包含票号、日期、金额、来源、交易组、重复状态、人工核验状态和规范化副本路径；疑似重复记录未被静默删除。
- [ ] 同金额电子发票与滴滴行程单先作交易关联并核对合计，标为“关联佐证”而不是两笔成本。
- [ ] 行程的时间、地点或用途异常只提示人工复核，不自动判断为私人费用，也不从敏感地点或人员信息推断私人生活。
- [ ] 未提供公司报销单模板或公司/报销人/部门/用途等关键字段时，不生成或伪造正式 `报销单.pdf`。
- [ ] 备用金 ¥3,000 仅录入现金收入区，不计入操作费用。
- [ ] 打车 ¥48.60 仅录一次，备注同时关联电子发票与行程单并注明不重复入账。
- [ ] 交通费、餐饮费、签单/酒店和物料费均位于正确支付区与模板类别中。
- [ ] 金额列由单价、数量、次数的公式生成；各支付区小计和资金合计保持公式关联。
- [ ] 无发票、未付款、未知经手人均如实标记，未被推断为已付款或已开票。
- [ ] 与项目决算表的实际成本关联未被硬编码或断开，且无公式错误。
