# 收支明细规则

## 明细表结构

常见“项目操作收支明细表”使用以下列：

| 列 | 字段 | 规则 |
| --- | --- | --- |
| A | 序号 | 各支付区独立连续编号。 |
| B | 时间 | 使用票据或支付凭证可确认的日期。 |
| C | 类型 | 使用模板下拉中的大类。 |
| D | 明细 | 使用模板下拉中的费用明细。 |
| E | 摘要 | 保留商户、用途及必要行程/服务信息。 |
| F:H | 单价、数量、次数 | 写入数值，金额由公式计算。 |
| I | 金额 | 保留 `=F行*G行*H行`；小计使用模板 `SUM` 公式。 |
| J | 发票 | 有发票时按模板标记“√”；无发票则留空或按模板约定填写。 |
| K | 备注 | 记录发票号、文件名、支付截图、行程单、待补信息和去重说明。 |
| L | 经手人 | 仅写已知姓名；未知使用 `[待确认]`。 |

## 分类边界

使用模板内已有下拉选项。常见操作费用明细包括餐饮费、交通费、住宿费、物料费、小费、人员补助、车辆补助、部门费用和其他操作费；签单或酒店类费用按模板要求归入“签单/酒店”。

- 一张发票与一笔支付对应时只录一笔；若一笔支付包含多个独立服务，可拆分，但拆分金额之和必须等于支付金额。
- 发票与行程单金额不一致时，优先录入应报销的实际支付或票面金额，并在备注说明差异；无法判断时标记待确认。
- 支付截图和电子发票可共同证明同一笔费用，不能合计为两笔成本。

## 固定区域

模板通常依次包含现金收入、现金支出、刷卡支出、已转账款项、未付款款项和资金合计。各区小计、资金合计、签字栏及“插入行”提示均是结构性单元格，必须保留。

如工作簿的项目决算表使用收支明细作为实际成本来源，不能移动明细表、修改表名、删除跨表引用，或用硬编码总额替换公式。
