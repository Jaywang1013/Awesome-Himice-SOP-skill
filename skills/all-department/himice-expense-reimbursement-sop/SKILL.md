# Himice 操作费用报销

优先使用用户提供的项目预算/决算工作簿，其中应有“结算-项目收支明细”（或同等命名的收支明细表）。若用户提供了杂乱的发票文件夹、支付截图或行程单，先按[票据接入、查重与归档](references/invoice-intake-and-archive.md)建立可人工核验的台账和副本归档，再录入工作簿。

若只提供票据而没有可编辑模板，仍可完成票据台账、规范化副本文件夹和待审核报销数据；要产出正式报销单 PDF 或更新项目决算时，必须索取公司的报销单/项目决算模板，不要凭空复刻正式表单。

## 收集与录入

先确认会议名称、每笔费用的日期/金额/支付方式、票据或付款凭证，以及经手人。来源不完整时，只填可核实字段，在备注和经手人中标记待确认；不要臆测费用类型或已付款状态。发票、行程单和支付截图之间可能互为佐证，必须按同一交易聚合，不以“文件数”作为费用笔数。

1. 将项目借款或备用金录入“现金收入”区；它不是现金支出费用。填写用途、金额和必要凭证信息。
2. 按实际支付方式录入现金、刷卡、已转账或未付款区，不要为了填满某一区而改变支付方式。
3. 每笔支出填写序号、时间、类型、明细、摘要、单价、数量、次数、发票状态、备注和经手人。金额列保留模板公式 `=单价*数量*次数`，不要改为文本或静态金额。
4. 将发票、付款截图、行程单等证据写入备注，并在发票列如实标记。行程单只是同笔交通费佐证时，在备注注明“佐证，不重复入账”；在台账标记其关联的发票/支付记录。
5. 原始资料明确是酒店签单、景点签单或住宿签单时，使用模板中的“签单/酒店”类别；普通操作费用则使用模板允许的操作费用明细。不能把一笔费用分录两次。
6. 需要增加明细时，在模板提示行上方插入，复制相邻行的公式、格式、数据验证和边框；同步扩展相应小计范围。不得删除提示行、支付分区、合计区或签字区。

## 决算联动

若工作簿含项目决算表，只更新实际成本和实际支付数据的必要输入区域；保留预计收入、预计成本和决算汇总公式。不要将收支明细金额手工重复填入总计单元格。

完成后核对：

- 每个支付分区的小计等于该区明细金额之和；资金合计等于现金、刷卡、已转账和未付款小计之和。
- 费用明细总额与决算表实际成本的关联口径一致；跨表公式保持有效。
- 不存在 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或 `#N/A`。若模板原有错误且无法安全判断引用目标，保留并向用户说明，不得凭猜测改写。

编辑前后均保留模板的字体、颜色、列宽、行高、合并单元格、打印设置和下拉验证。
