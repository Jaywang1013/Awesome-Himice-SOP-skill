# Himice 协作人业绩分配

使用用户提供的“协作人业绩分配表（预估业绩使用）”模板。该表是新项目预算发起时的配套材料；项目结束后的最终确认分配属于另一审批阶段，不能擅自改写预估表或推断最终比例。

## 必填事实

开始前收集：

1. 鱼鹰项目名称及编号
2. 报账人
3. 预估营业额和预估毛利率
4. 活动开始、结束时间、内容、地点和人数
5. 客户全称及纳税人识别号（如适用）

“是否竞标”“是否本地客户”“业务类型”“客户来源/类型”及销售、谈判、执行人员与比例必须有用户来源；没有明确资料时留空或按模板标为待确认，不能自行判断。

## 填写与验收

1. 在项目数据行写入已确认事实，保留文本、日期和金额的原有数据类型及格式。
2. 毛利润使用模板公式 `=营业额*毛利率`；不要手工输入计算结果。营业额是数值，毛利率是数值百分比，不要写为带百分号的文本。
3. 仅在用户提供明确角色和比例时填写协作角色列。若模板或用户要求合计比例校验，确认同一角色的拆分比例为 100%。
4. 不修改模板中的备注、流程说明、工作表结构或列标题；新增项目使用复制的格式化数据行。
5. 检查日期顺序、毛利润公式、百分比格式和公式错误，并渲染核对标题、长项目名和客户字段没有截断。

读取 [分配表字段说明](references/collaborator-allocation-fields.md) 后再处理字段映射或缺失信息。
