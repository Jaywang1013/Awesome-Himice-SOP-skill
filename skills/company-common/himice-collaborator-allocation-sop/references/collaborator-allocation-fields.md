# 协作人业绩分配表字段说明

## 项目数据列

| 列 | 字段 | 写入规则 |
| --- | --- | --- |
| A | 序号 | 项目行连续编号。 |
| B | 鱼鹰项目名称（含编号） | 保留项目归属地、编号和名称。 |
| C | 报账人 | 原样填写。 |
| D | 营业额（估） | 数值。 |
| E | 毛利率（估） | 数值百分比。 |
| F | 毛利润（估） | 保留 `=D行*E行` 公式。 |
| G:H | 活动开始、活动结束 | 使用日期值，开始不晚于结束。 |
| I:K | 活动内容、地点、人数 | 原样填写；人数为数值。 |
| L:X | 竞标、本地客户、业务、客户、来源及协作角色 | 仅填写明确提供的事实。 |

## 流程边界

该表仅用于预估业绩和预算发起。项目结束后应走最终确认的协作人分配审批；审批完成的项目不应在此表中推断或替换最终方案。

填写客户信息时保留用户提供的客户全称和纳税人识别号；未提供联系人、第二客户或来源时留空，避免编造业务信息。
