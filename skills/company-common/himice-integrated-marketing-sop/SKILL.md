# Himice 整合营销技能包

先查找用户提供的 `himice-brand-context.md`。如不存在，先用 [集团品牌上下文模板](assets/himice-brand-context.template.md) 收集已知事实；在信息不足时继续完成可做部分，并明确列出资料缺口。不要虚构集团品牌承诺、客户案例、项目成果、获奖、金额、数据或合作关系。

## 路由

只读取当前任务所需参考资料；多阶段任务按下列顺序串联，不重复收集已确认事实。

| 用户目标 | 读取 |
| --- | --- |
| 集团/业务单元定位、服务产品化、销售叙事 | [定位与服务主张](references/positioning-and-service-offer.md) |
| 年度传播、项目招商、活动预热/现场/会后传播、渠道节奏 | [活动整合营销](references/campaign-and-content.md) |
| 官网/案例页、公众号、视频号、小红书、LinkedIn、销售单页、邮件、脚本 | [活动整合营销](references/campaign-and-content.md) |
| 公开竞品研究、渠道表现复盘、测试设计、指标解读 | [市场研究与效果复盘](references/market-intelligence-and-measurement.md) |

## 共同工作方式

1. 先确定唯一业务目标、优先受众、核心行动和可用证据。品牌宣传、销售获客、活动报名与客户维护不可混为同一个目标。
2. 所有营销方案都以可执行成品交付：定位陈述、活动传播 Brief、内容成稿、渠道排期、创意制作单或复盘表，而不是泛泛建议。
3. 每项对外主张都要能对应已授权的事实来源。证据不足时写 `[待补：证据类型]`，并说明由谁确认；不以“行业领先”“效果显著”等空泛词替代证据。
4. 对外发布前区分集团品牌、业务单元、客户与活动项目的名称/标识使用权限。涉及客户名称、数据、肖像、现场影像、合同金额、活动嘉宾或媒体合作时，默认需业务与品牌负责人确认。
5. 市场规则、平台政策、广告规格和搜索引擎行为属于时效信息；有网络条件时须核验官方来源并标明核验日期。不得直接操作广告账户、媒体账户、客户 CRM 或付款。

## 交付标准

营销文案先给可直接使用的成品，再给简短理由。评估分数必须注明是启发式评分而不是实际效果。每份策略、研究或复盘的末尾都要包含“已验证事实”“待确认项”和“下一步最小验证动作”。

当活动方案需要预算、供应商成本或报销时，转交相应的 Himice 财务技能；不要在本技能内估算或登记财务数据。
