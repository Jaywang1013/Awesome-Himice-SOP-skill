# 活动整合营销与内容制作

用于集团品牌传播、客户活动招商、会前预热、现场内容、会后案例传播和销售内容。先明确一个业务目标和一个核心行动；同一活动可有多条内容线，但每条内容只服务一个行动。

## 整合营销 Brief

```markdown

## 背景与目标
- 业务目标：
- 优先受众：
- 核心行动：
- 已确认的证据与授权：

## 核心信息
- 一句话主张：
- 三条支撑信息：
- 需避免的承诺/敏感内容：

## 内容与渠道节奏

| 会前 |  |  |  |  |  |  |
| 现场 |  |  |  |  |  |  |
| 会后 |  |  |  |  |  |  |

## 创意制作单
每项分别列出：目的、受众、文案、视觉/视频要点、规格、必备素材、授权状态、审核人。

## 待确认项
```

## 文案输出

- 先交付完整成稿，后说明选择理由。为主标题提供 3–5 个真正不同角度的备选，不要只替换形容词。
- 对公众号、视频号、小红书、LinkedIn、官网或邮件，按该渠道的受众、格式和内容习惯重写，不能把同一段话直接复制到全部渠道。
- 任何时间、地点、嘉宾、客户、数据、优惠、报名名额、活动规则或发布截止期，必须来自确认材料；不确定时用 `[待确认]`。
- 现场照片、视频、访谈、客户 Logo 与嘉宾姓名在对外使用前检查授权。没有授权时提供不含敏感主体的替代内容建议。

## 常见链路

- 服务定位 → 官网/销售单页 → 招商内容 → 会后案例。
- 年度主题 → 月度内容主题 → 单次活动预热 → 现场素材 → 会后复盘与线索跟进。
- 竞品研究发现 → 服务主张修订 → 内容角度 → 小范围渠道测试。
