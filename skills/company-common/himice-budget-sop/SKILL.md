# Himice 项目预算表

使用 `assets/【项目预算表】鱼鹰号+活动名称.xlsx` 作为空白模板；优先保留客户提供的模板版本。

## 先收集表头信息

在开始填写预算表前，确认以下六项。缺少任意项时，先一次性索取缺项，不要虚构。

1. 会议名称
2. 会议人数
3. 执行时间（开始、结束；若只给日期范围，确认是否按自然日计算）
4. 公司参与人数
5. 会议负责人
6. 会议报账人

写入主表：`B2` 会议名称、`B3` 执行时间、`G3` 会议人数、`G4` 会议负责人、`G5` 会议报账人。将公司参与人数写入 `K2:S2` 的人员参与说明；无人员结构时保留各类别“待确认”，但写入总人数。

仅在需要精确计算人员补助时，再收集公司参与人员的员工类型与职级。不要把试用期、实习生或管理层默认按正式员工计补。

## 填写报价与成本

1. 读取客户报价中的板块、明细、规格、单价、数量、次数、小计，以及“会议服务商代付”等代付标记。
2. 先分类代付：酒店会场租赁、酒店住宿、酒店餐饮、机票、动车分别写入红字的 `57:61` 行；茶歇不属于代付服务费基数。报价明确标注代付的项目不得留在普通物料板块或另建“嘉宾差旅费”重复计算。
3. 其余项目按客户报价顺序写入主表：板块在 A 列、明细与规格在 B 列、预计收入单价/数量/次数在 C:E，F 列使用 `=C行*D行*E行`。
4. 对同一板块的连续行**自动纵向合并 A 列**：先取消目标区域已有合并，再按报价中每个连续板块的首行至末行合并；只在首个单元格写入板块名。单行板块不合并。板块名和明细必须采用客户报价的叫法。报价中的 0 必须写入数值 0。
5. 初版预算将预计成本与预计收入逐项一致：将 C:E 镜像到 G:I，J 列使用 `=G行*H行*I行`。除非用户提供供应商成本，否则不要自行估价。现金提取类物料仅给其预计成本单项小计（J 列）加黄色填充；不填色单价、数量、次数，也不填色代付、服务费和税费。
6. 报价未出现的普通明细必须清空；如结构性删除行会破坏固定的代付、操作费用或汇总区，则保留该固定行但不填入金额。新明细超出容纳范围时，在同类板块内插行，复制相邻行的格式、公式、验证规则和合并逻辑；同步扩展小计与总计范围。不要删除或移动列。
7. 使用服务费公式：`B62=SUM(F57:F61)*0.06`、`C62=B62`、`F62=C62*D62*E62`。茶歇行 `F56` 不计入代付服务费；代付基数仅为五项专用行。预计成本侧保持同样的金额逻辑。
8. 报价若单列“代付服务费5%”，以公司标准 6% 公式替换，避免重复；客户单列项目服务费或税费则保留其明细与金额，并避免在模板汇总区重复叠加。

## 操作费用默认标准

将以下标准写入主表“操作费用模板”的单价/数量/次数区域；按实际公司参与人数、执行天数和住宿晚数更新数量与次数。

| 项目 | 单价 | 数量 | 次数 |
| --- | ---: | ---: | ---: |
| 餐饮费 | ¥70/人/天 | 公司参与人数 | 执行天数 |
| 交通费 | ¥1,000/人 | 公司参与人数 | 2 |
| 住宿费 | ¥300/间/晚 | 向上取整(公司参与人数/2) | 住宿晚数 |

人员补助通过“人员补助表”按人员逐行计算：正式员工 ¥120/人/天；试用期和实习生 ¥70/人/天；M 级管理层无人员补助。B1–B6 为项目助理/项目专员职级。人员结构未提供时，只保留单价标准，不推断补助人数或金额。

## 格式与验收

- 只修改必要的内容、公式与合并单元格；保持模板的字体、颜色、列宽、行高、冻结列和所有数字格式。
- 金额保留模板人民币 `¥#,##0.00` 格式，且保留两位小数；不要用文本代替数字。
- 检查逐项小计、板块小计、税前合计与报价表一致；首版成本逐项与收入一致时，单独确认操作费用的影响。
- 扫描并修复 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A`。渲染主表并确认表头、合并板块和金额没有截断。

读取 [预算表规则](references/budget-rules.md) 以获取单元格映射、默认标准和核对口径。
