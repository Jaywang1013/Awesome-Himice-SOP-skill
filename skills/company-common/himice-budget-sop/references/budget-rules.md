# 预算表规则

## 表头单元格

| 信息 | 位置 | 写入规则 |
| --- | --- | --- |
| 会议名称 | `B2` | 原样写入 |
| 执行时间 | `B3` | 写入开始至结束；不推断日期 |
| 会议人数 | `G3` | 数值或用户给出的明确文本 |
| 会议负责人 | `G4` | 原样写入 |
| 会议报账人 | `G5` | 原样写入 |
| 公司参与人数 | `K2:S2` | 保留既有说明文字，并写明总人数；人员分类未知则标记待确认 |

## 代付服务费

酒店会场租赁、酒店住宿、酒店餐饮、机票、动车纳入代付服务费基数；茶歇不纳入。报价中标注“会议服务商代付”的项目必须映射到这五项专用行，不能与普通物料或嘉宾差旅费重复。服务费率为 6%。

主表公式：

- `B62=SUM(F57:F61)*0.06`
- `C62=B62`
- `F62=C62*D62*E62`

客户报价若出现“代付服务费5%”，用上述 6% 公式生成代付服务费，不能同时保留两笔。代付基数只取五项专用行；未报价的专用行可以保留为空或零值，但不得影响求和。

## 首版成本口径

如果用户只提供客户报价，先将每条预计成本镜像为预计收入，供项目同事后续以供应商报价调整。操作费用按已确认的人员、天数、晚数单独叠加；未知的人员结构不得猜测。

现金提取类物料仅在预计成本单项小计（J 列）使用黄色填充；单价、数量、次数及代付/服务/税费项目不标黄。报价未出现的普通明细清空；固定汇总和代付行保留结构以保证公式稳定。
