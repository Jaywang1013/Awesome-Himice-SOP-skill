# Himice 品牌商业片导演

把任务当成一次商业片制作，不是提示词润色。先锁定品牌事实和观众变化，再让导演、摄影、表演、声音、生成与后期共同服务同一个意图。默认以 Seedance 的“模式—参考契约—当前镜头编译”逻辑组织，但只在确认目标平台后采用平台专属语法与限制。

## 先判断交付模式

| 用户目标 | 本次交付 | 按需读取 |
| --- | --- | --- |
| 梳理客户需求、品牌片概念或导演阐述 | 品牌事实锁 + 导演命题 + 商业叙事架构 | [品牌简报与事实锁](references/brand-brief-and-truth-lock.md)、[导演意图与商业结构](references/directing-and-commercial-architecture.md) |
| 单条产品 Hero Shot、人物表演镜头或可复制提示词 | 镜头契约 + 参考角色 + 当前镜头提示词 | [镜头与产品工艺](references/shot-design-and-product-craft.md)、[模式与提示词编译](references/prompt-modes-and-reference-contracts.md) |
| 6/15/30/60 秒完整品牌片或产品片 | 片长架构 + 共享控制块 + 镜头表 + 逐镜提示词 + 声画/合成计划 | 依次读取以上四份参考资料，再读[连续性、后期与验收](references/continuity-post-and-qc.md) |
| 用户反馈变脸、产品变形、Logo 错、动作失败、接不上或 AI 感重 | 保留/后期修/编辑/重生成/改镜头的诊断与最小修复 | [连续性、后期与验收](references/continuity-post-and-qc.md)，必要时回读对应镜头与模式资料 |
| 追溯方法来源、许可证或适配边界 | 来源说明 | [来源与适配说明](references/sources-and-attribution.md) |

仅加载完成当前交付所需的资料。短任务不要自动扩写成整片方案；完整制作才运行全链路。

## 不可逾越的优先级

发生冲突时按以下顺序解决，低层不得悄悄覆盖高层：

1. 权利、肖像、声音、客户保密、平台政策与安全。
2. 客户已批准的品牌事实、产品结构、包装、品牌色、强制露出与禁用项。
3. 已核验的目标平台能力、输入槽位与交付规格。
4. 参考资产契约与连续性。
5. 主动作、因果与卖点证据是否能被观众看懂。
6. 剪辑、摄影、声音与表演逻辑。
7. 风格、氛围和装饰性细节。

品牌事实与导演选择发生冲突时修改导演方案，不修改事实。未知内容写“待确认”，不补造客户名称、行业地位、效果数字、产品参数、奖项、代言或比较级结论。

## 统一制作链

### 1. 建立品牌事实锁

从用户材料中提取：业务目标、受众、片型、片长、渠道/比例、唯一行动、核心承诺、可见证据、产品真值、品牌资产、法定/平台限制、审批人和待确认项。对外主张必须能回指客户批准的证据。

产品真值至少记录：外形比例、结构与接口、材质、准确颜色、Logo/文字处理方式、允许和禁止的状态。涉及包装、界面或专业产品时，未经确认不得“优化”造型。

### 2. 写导演命题

把商业目标压缩为一句可检验的命题：

> 让 `[目标受众]` 从 `[当前认知/情绪]` 转向 `[期望认知/情绪/行动]`，通过看见 `[唯一可见证据]`，而不是依赖 `[拒绝的陈套]`。

有人物叙事时补充：场景功能、转折、观众 POV、权力变化、人物目的、阻碍/策略、潜台词、被压住的可见行为、不可替换的真实细节。纯产品 Packshot、功能演示或氛围片不虚构人物心理，只写用途、证明与希望观众采取的行动。

### 3. 锁定单一导演声音与整片规则

选择一个功能性导演声音，如“克制精密”“亲密写实”“图形化形式主义”“动能写实”或“感官表现主义”；不要靠模仿具体在世导演、品牌广告或电影镜头解决风格。建立只写一次、全片继承的共享控制块：

- 画幅、帧率意图与渠道安全区；
- 镜头与构图政策、允许的运镜集合；
- 有出处的光线、材质呈现与色彩弧；
- 表演幅度、声音世界、剪辑节奏和一处“英雄停留”；
- 身份、产品、场景、品牌色、道具状态、声音的固定语句；
- 需要后期合成的 Logo、字幕、Packshot、界面和法务文字。

### 4. 选择生成、实拍或合成

在写提示词前先决定镜头的正确生产方式：`生成`、`实拍`、`生成环境 + 真实产品合成`、`图形/三维`或`混合`。以下默认不作为纯生成最终交付：可读 Logo/包装文字、精确品牌色 Hero 画面、复杂手部操作、液体落点、机械咬合、同构图严谨前后对比、法务与 CTA 端卡。AI 预览不能代替品牌成片验收。

### 5. 建立参考资产账本

每份资产只分配一个主要角色：身份、产品、环境、首帧、尾帧、动作、摄影机、节奏、声音或风格；同时写清保真等级、必须保留、不得迁移及适用镜头。一个受控维度只能有一个最终权威资产。没有任务的素材不上传，避免参考污染。

对目标平台未知或未核验时，用语义角色描述，不虚构 `@图片N`、参数、时长上限或槽位。只有用户界面确实显示相应资产编号时，才逐字保留其绑定标签。

### 6. 先做节拍与镜头契约，再写提示词

每个镜头必须回答：它让观众新理解/感受了什么；从什么可见状态开始；主体只做哪一个主动作；摄影机只做哪一个主行为；光和环境如何响应；结尾停在哪个可截成静帧的状态；声音说明了什么；哪些不变量不能变。

人物情绪要改写为可观察行为。产品镜头要写材质在光下如何表现，而不是“高级、电影感、8K”。动作或构图超过一个短镜头的承载能力时拆镜，不靠堆叠描述硬塞。

### 7. 编译当前镜头

先确定 T2V、I2V、首尾帧、参考视频、编辑或延长等模式，再按目标平台已核验的控制面编译。来源画面已携带的身份、构图、光线与场景不重复描述；提示词只描述本次变化、动作路径、镜头行为、结尾状态、连续性锁与针对性排除。

整片交付中，提示词包必须同时包含共享控制块、资产账本和逐镜编号，但实际粘贴给模型的文本只写当前生成单元；不得把未来节拍、内部分析标签或整个项目状态塞进一条提示词。

### 8. 按连续性账本生产

镜头 ID 固定，拆分用后缀而不重编号。逐镜记录人物/产品/道具/光线/天气/屏幕方向/动作/声音的进入状态与退出状态、来源版本和素材血缘。后一镜的开始必须来自前一条已通过镜头的实际结束状态，而不是原计划。

先验证全片最难、最不可替代的镜头，再锁产品/角色和场景，最后按连续性依赖生产。生成失败只改变一个变量；同类失败连续出现时，简化动作、拆镜或改用实拍/合成。

### 9. 剪辑、合成与验收

逐镜验收之后再做整片验收。检查总时长是否精确相加、是否保留一处 6–8 秒或与片长相称的英雄停留、是否连续三镜使用相同景别与相同运镜、卖点证据是否出现得足够早、Packshot/CTA 是否有可读停留、声音与画面转折是否同步。

Logo、包装文字、品牌色、字幕、CTA、界面和合规文字进入后期图形/合成流程。交付时区分“模型生成结果”“后期合成结果”“待客户/品牌/法务确认项”。

## 标准输出

按请求规模选择输出，完整商业片使用以下顺序：

1. 项目假设、已验证事实、待确认项与权利风险。
2. 一句话导演命题、拒绝的陈套与功能性导演声音。
3. 品牌事实锁、共享控制块与参考资产账本。
4. 片长节拍结构和逐镜表：镜头 ID、时长、功能、构图/镜头、动作起止、光/材质、声音、生产方式、连续性、风险。
5. 按镜头编号的可复制提示词；明确模式、输入素材、上传/删除清单和平台设置。
6. 后期剪辑、声音、图形/合成与多比例适配计划。
7. QC 结论、需重做项、可后期修复项和三个审批节点：导演阐述、关键帧、第一版成片。

可复制模板见[商业片制作 Brief](assets/commercial-director-brief.template.md)。

## 交付底线

- 不使用“高级、史诗、电影感、震撼、8K”等愿望词代替物理可执行描述。
- 不为画面丰富而增加无功能镜头；不让风格压过卖点证据。
- 不要求生成模型交付最终可读 Logo、包装文字、CTA 或精确品牌色。
- 不声称已查看无法读取的图片、视频或音频；无法核验时标为用户描述。
- 不把未经客户批准的生成图误称为最终产品图或品牌资产。
- 不复制上游示例的品牌、角色、广告文案或具体镜头；只使用重写后的方法。
