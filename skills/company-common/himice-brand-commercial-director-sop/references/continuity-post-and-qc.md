# 连续性、后期与验收

## 连续性账本

为每条通过镜头记录：

| 字段 | 内容 |
| --- | --- |
| 血缘 | 项目 ID、镜头 ID、版本、模式、来源关键帧/视频、平台 |
| 人物 | 身份、服装、发型、朝向、位置、视线、进入/退出边 |
| 产品 | 型号、外形、颜色、Logo 状态、朝向、开合/使用状态 |
| 场景 | 空间结构、时间、天气、光源、光向、色温 |
| 道具 | 所有人、位置、物理状态、何时改变 |
| 动作 | 实际起点、实际终点、未完成动作、不得重播的节拍 |
| 声音 | 环境底、动作声、台词/音色、音乐相位与退出状态 |
| 审批 | 通过/拒绝、审核人、时间、已接受妥协 |

已通过素材的实际结束状态覆盖原计划。拒绝镜头不得成为续拍来源。后续提示词在前一依赖镜头通过前保持暂定。

## 整片连续性检查

- 产品几何、接口、Logo 位置、颜色和包装状态没有漂移；
- 人物身份、服装、肤色/妆发、身高比例和声音连续；
- 道具所有权和状态变化有因果，不凭空出现或回退；
- 主光方向、天气、湿度、损伤、消耗量等符合时间顺序；
- 屏幕方向、动作轴、视线和进出画方向可剪接；
- 相邻镜头通过动作、视线、形状、声音或意义建立明确接点；
- 未批准的客户事实、产品功能和品牌文字没有进入画面或旁白。

其中产品真值、人物身份或参考标签错误为硬失败，不用“整体好看”抵消。

## 后期不是补救，而是设计的一部分

以下从 Brief 阶段就标注为后期任务：

- 官方 Logo、包装文字、产品型号、字幕、CTA、法务脚注；
- 精确品牌色和镜头间色彩匹配；
- 官方产品/界面与生成环境的跟踪合成；
- 旁白、音乐、环境、动作音效与最终混音；
- 多比例裁切、字幕安全区、横竖版重构；
- 必要的颗粒、暗角和质感统一。

避免过度锐化、AI 补帧或“一键超清”把真实纹理变回蜡质。输出规格应根据客户母版、平台官方要求和源素材核验，不把固定帧率/码率写成所有项目的万能标准。

## 全片节奏与可读性

1. 镜头时长之和精确等于目标片长。
2. 前 1–2 秒提供停留理由；产品片尽早让产品或效果出现。
3. 有一处较长英雄停留；端卡有足够阅读时间。
4. 不连续三镜使用同一景别和同一摄影机行为。
5. 快切有信息增量，慢镜有情绪或证据增量。
6. 声音的重音、停顿、前响或尾响帮助转场，而不是每镜重新开始。
7. 竖版中的主体、产品、Logo/字幕合成位避开平台 UI 安全区；横竖版关键构图必要时独立生成。

## 单镜头验收

- **意图**：这一镜唯一功能是否清楚；所有摄影/光/表演/声音是否同向。
- **品牌**：产品、色彩、主张、Logo/文字处理是否符合事实锁。
- **动作**：起点、触发、变化、响应、跟随和终点是否可读。
- **摄影**：没有无动机运镜；构图物理可行；主体没被镜头动作掩盖。
- **材质**：反射、玻璃边缘、哑光纹理、液体和微距景深可信。
- **连续性**：与上一通过镜头的实际退出状态一致。
- **伪影**：变脸、多指/多手、产品复制、变形、闪烁、错误文字、漂移倒影。
- **可剪性**：首尾留有必要余量，存在明确切点和可用声音。

## 最小修复阶梯

先判断：`保留`、`后期修`、`编辑现有素材`、`同提示词重抽样`、`重写提示词`、`重做关键帧`、`拆镜/换生产方式`。

1. 写带时间码的诊断：什么保持正确、什么在何时出错、属于品牌/参考/动作/摄影/连续性/物理/声音哪一轴。
2. 下一版本只改一个变量；保留成功部分的约束。
3. 随机小伪影可同提示词抽样；结构性重复失败不要继续加形容词。
4. 两次同类结构失败后，缩短动作或锁定摄影机；第三次仍失败，拆镜、首尾帧、实拍或合成。
5. 中段只坏一处且平台支持编辑时，以源片为唯一母版、一次改一处，并列明其余保持不变。
6. 延长只能接已裁到正确衔接帧的尾部，不重拍旧结尾、不跨镜头改变机位。

修复记录示例：

```text
镜头/版本：SH04_v05
结论：拒绝
保持正确：产品轮廓和相机左侧主光全程稳定。
故障：00:02.8 起瓶盖多出一条接缝；品牌/产品几何轴。
下一步：只改生产方式——锁定官方产品静帧，重新生成移动高光环境并在后期合成；不再重抽纯生成产品。
```

## 最终交付包

- 已批准导演阐述、品牌事实锁与待确认项；
- 最终镜头表、共享控制块、参考资产账本和连续性账本；
- 逐镜关键帧、源素材、批准片段、提示词与版本记录；
- 编辑时间线、声音计划、Logo/包装/字幕/CTA 合成文件；
- 横竖版母版、交付规格、权利/法务/品牌审批记录；
- 已接受妥协、未解决风险和后续可改进项。
