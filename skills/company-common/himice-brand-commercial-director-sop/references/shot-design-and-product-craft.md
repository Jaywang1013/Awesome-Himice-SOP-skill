# 镜头设计与产品工艺

## 镜头契约

每个镜头在写提示词前完成：

| 字段 | 合格标准 |
| --- | --- |
| 功能 | 观众在这一镜之后多知道/感受什么 |
| 起始状态 | 可见、静态、与输入素材一致 |
| 主动作 | 一个主体、一个有对象的动作、速度和方向明确 |
| 摄影机 | 一个主要行为或明确锁定，并说明为何服务意图 |
| 光/环境响应 | 有物理来源，只写一项必要变化 |
| 结束状态 | 能截成静帧，明确主体/产品/道具/构图状态 |
| 声音 | 环境、动作、台词或留白中的一个明确职责 |
| 连续性 | 身份、产品、道具、光线、屏幕方向和声音状态 |
| 风险与替代 | 绿/黄/红；生成、拆镜、实拍或合成 |

一个短镜头原则上只容纳：一个主动作 + 一个摄影机行为 + 一个环境响应。动作必须有结束状态。若出现多个因果步骤、接触/传递、多人协调、复杂运镜或形变，先拆镜。

## 把情绪变成表演

不要写“她很感动、他很自信”。改写为：目光目标、呼吸、下颌/嘴角/眉部的小变化、手指或道具动作、身体与空间的距离、停顿和最后姿态。

微表演示例：

```text
她看向产品的状态灯，吸气变浅；右手拇指在包装边缘停一下，没有马上打开；
听到提示音后肩膀下降一点，才抬眼看向同伴。结尾右手仍扶着包装，目光停在同伴脸上。
```

每个节拍选 2–4 个相互连续的可观察环节，不堆全脸肌肉词。表演幅度以真实人物和品牌语气为准。

## 产品 Hero 的控制原则

产品镜头要表现材质和真值，而不是只表现形状。生成最稳的运动通常来自光：产品静止、摄影机锁定或极小移动，让一个大面积可控光源的反射沿表面移动。产品或摄影机大幅旋转会迫使模型逐帧重建几何与 Logo，风险显著增加。

### 材质灯光

- **高光材质（金属、烤漆、亮塑）**：设计它反射什么。写明一个大面积亮反射的形状和暗侧负补光；排除摄影师、灯具、窗格和第二个产品的倒影。
- **透明材质（玻璃、液体、凝胶）**：明场用背后亮面表现暗边，暗场用两侧窄条光表现亮边；液体另设可见光源。
- **哑光材质（粉体、织物、纸、陶）**：用浅角度掠射光制造微小阴影，正面均匀光只会得到平面色块。
- **微距**：明确唯一清晰平面；避免不可能的“100mm 微距、极近、f/2.8、整个产品全清晰”。需要全清晰时后退裁切、让可读面平行传感器或改用实拍/合成。

## 产品片镜头语法

| 镜头 | 证明什么 | 推荐生产方式 |
| --- | --- | --- |
| Hero | 产品完整轮廓与渴望感 | 生成环境/光 + 官方产品合成；低风险时可生成预览 |
| 材质微距 | 卖点所依赖的纹理、光泽、颗粒或结构 | 无 Logo 时适合生成；指定掠射光和清晰平面 |
| 使用/应用 | 产品怎样完成一个动作 | 手部、面部、精密接触叠加时优先实拍；生成则把手预置到位并缩短接触 |
| 前后对比 | 同构图只改变一个变量 | 两张批准静帧或首尾帧；不在单条自由生成中要求一切不变 |
| Packshot | 正确产品、Logo、品牌色 | 实拍、官方三维或合成，不把生成文字当最终稿 |
| 端卡 | Logo、批准主张、CTA、法务字 | 后期图形，非视频生成任务 |

## 不应硬生成的镜头

- 需要准确、可读、跨帧稳定的 Logo、包装文字或屏幕界面；
- 品牌色本身就是验证对象；
- 手指进行精细安装、按钮组合、复杂穿戴或多手交接；
- 液体持续倾倒并准确落入容器、机械部件啮合或透明结构内运动；
- 同一人物/产品在连续镜头中必须达到法务或工程级一致；
- 产品效果属于医学、金融、性能或比较性主张，但没有已批准证据。

替代顺序：简化动作 → 用剪切显示动作前后两态 → 首尾帧桥接 → 实拍关键动作 → 生成环境并合成真实产品/界面。

## 风险预检

- **绿**：静态环境、无脸材质、单主体简单动作、锁定镜头。
- **黄**：人物特写、短接触、已锁参考的连续镜头、首尾帧变化。
- **红**：多人协调、复杂手部、长时间身份保持、产品转动带 Logo、液体/机械精密物理、多维度同时变化。

红色镜头在写提示词前必须拆解或改生产方式。先测试整片最难且不可替代的镜头；它无法成立时，尽早重写结构。
