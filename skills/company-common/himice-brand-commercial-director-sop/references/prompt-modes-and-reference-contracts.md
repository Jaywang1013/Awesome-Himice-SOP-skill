# 模式、参考契约与提示词编译

## 先确认平台，再确认模式

平台能力和参数会变化。仅使用用户当前界面或官方资料确认的模式、时长、分辨率、参考数量、音频和延长能力；未知时保留平台中立提示词，不猜参数。

| 模式 | 来源携带什么 | 提示词主要写什么 |
| --- | --- | --- |
| T2V | 无输入画面 | 主体/产品、环境、动作、摄影机、光、构图、声音和约束 |
| I2V | 首帧携带身份、构图、场景、光和材质 | 从可见起点发生的变化、摄影机、环境响应、结束状态和连续性 |
| 首尾帧 | 两端构图和状态均已批准 | 两帧之间唯一连续桥接、节奏与不得变化项 |
| 参考视频/动作 | 来源携带动作、摄影机、节奏或声音之一 | 明确只迁移哪一维，不迁移人物、背景、造型或品牌 |
| 编辑 | 原片是唯一母版 | 一次只改一处，列出其余必须保持不变的内容 |
| 延长 | 已通过片段的实际尾帧与运动状态 | 描述观察到的尾帧和下一动作；不重播、不重置、不跨镜头剪切 |

## 参考资产契约

每份素材登记：

```text
资产 ID / 平台标签：
主要角色：身份 | 产品 | 环境 | 首帧 | 尾帧 | 动作 | 摄影机 | 节奏 | 声音 | 风格
保真等级：完整保留 | 部分保留（列明） | 属性迁移（列明目标） | 松散参考
必须保留：
不得迁移：
适用镜头：
```

规则：

1. 每份素材一个主要角色；一份素材可以约束多个维度，但每个维度只能有一个最终权威来源。
2. 场景图只负责空间/光/构图时，明确“不采用其中的人物、文字和商标”；角色图明确“不采用背景”；声音锚点明确“不采用其画面、场景和运镜”。
3. 每条生成只上传会在当前镜头中承担任务的素材。离场人物、上一场景、旧包装和无关参考必须删除。
4. 产品开/合、干/湿、完整/破损等状态需要独立资产或明确时间状态；资产锁外形，文字锁当前状态。
5. 平台标签必须逐字保留，不翻译、不改大小写、不自行重排编号。

## 来源携带状态

I2V、延长和编辑中，输入画面已经证明的身份、构图、光线、服装、产品和场景不要全部重复描述。重复描述会稀释动作并可能与画面冲突。先列“来源已有”，再只写本次 `delta`：

```text
摄影机行为。主体从可见起点开始，以速度和方向完成一个主动作。
一个环境元素作出轻微响应。结尾停在可验证状态。
保持必要不变量。避免当前镜头最可能出现的 2–4 个具体错误。
```

## 四种编译形状

### I2V：动作优先

```text
[摄影机锁定或一个移动]。[主体从输入画面的可见状态]开始，[按速度与方向完成一个动作]。
[光或环境的一项响应]。结尾停在[可截成静帧的状态]。
保持[身份/产品/道具/光线]。避免[当前风险的具体实例]。
```

### T2V：完整描述

```text
[格式/质感]。[具体主体或产品]。[地点、时间与可见环境]。
[唯一主动作]。[景别、镜头、角度与一个摄影机行为]。
[光源、方向、性质和材质反应]。[构图]。[可用时的声音]。[针对性约束]。
```

### 首尾帧：只写桥

```text
从已批准首帧连续过渡到已批准尾帧；两者之间只发生[一个变化]。
摄影机[锁定或单一路径]，运动[节奏]。
[身份、产品、场景、光向]保持完全一致；不得出现[针对性错误]。
```

若无法用一个从句描述两帧之间的桥，拆镜。

### 延长：从实际尾帧继续

```text
从上一条已通过片段的最后一帧继续。当前可见状态是[实际观察到的静态状态]。
接下来[一个新动作]；摄影机[保持或一次明确变化]。
保持[仍在画面中的不变量]。不重播、不重置、不剪切。避免[风险]。
```

延长只延续同一镜头。下一个镜头改变景别、机位或摄影机高度时，应独立生成并剪辑。

## 当前镜头编译纪律

- 最终提示词是自然、直接、可执行的制作语言；结构化表格用于规划，不强制塞入模型。
- 只输出当前镜头或平台能够承载的一个生成单元。整片未来事件不提前写入。
- 一条提示词只有一个主动作、一个摄影机行为、一个局部终点。
- 排除项只写当前镜头的真实风险，用具体实例替代“不要 AI 感、不要现代物品”等大类。
- 风格由物理选择表达：焦段/视场、机位、光源、反射、材质、表演、声音和剪辑；不使用形容词堆。
- 中文界面默认给中文生成提示词；英文优先平台可给英文，并保留所有平台资产标签原样。除非用户要求，不重复输出中英两套。

## 声音与音色

声音至少承担一个职责：建立空间、证明动作、连接剪辑、制造转折或承载批准台词。跨条独立生成的角色声音不会天然保持一致时，准备 5–10 秒、只包含目标角色的干净音色锚点；写明仅迁移音色/语气，不采用旧画面。语言、方言、口型和语速要求仍需单独声明。

音乐优先在后期建立整片节奏。除非目标平台和项目确实需要原生音乐，不让每条镜头各自生成不一致配乐。
