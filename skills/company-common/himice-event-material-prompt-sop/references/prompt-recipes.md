# 延展物料双图提示词配方

先复制“通用双图前缀”，再拼接对应物料配方。方括号内容仅在用户提供了确切信息时替换；未提供时保留 `[待补：字段]`。

## 通用双图前缀

```text
图 1 是新的活动主视觉 KV，图 2 是物料效果参考样机。以图 2 的最终构图、物体轮廓、可印刷面、拍摄角度、尺寸比例、材质、背景、灯光和阴影为唯一依据；完整移除图 2 可印刷面上已有的 Logo、标题、文字、日期、人物和装饰图案，只把图 1 的视觉设计真实应用到指定可印刷面。

将图 1 视为真实设计源稿：严格保留其中已有的 Logo、图形、标题、数字、日期和文字，不翻译、不改写、不增删、不生成相似或乱码文字。允许为适配物料比例等比缩放、合理裁切、留白或延展背景纹理，但不得拉伸 Logo、人物、文字、数字或核心图形；比例不适合时，优先保留核心识别元素而不是硬塞整张海报。

贴图必须跟随图 2 原有的透视、曲面、折角、褶皱、高光、反射、遮挡和接触阴影。不可改变样机的轮廓、支架、五金、绳带、纸张、容器、人物手部或背景，不增加无关物体。只输出一张完成后的真实摄影样机，保持图 2 的原始画幅和分辨率；不要输出参考图拼贴、前后对比、说明文字、标注线、边框或水印。
```

## 01｜悬挂横幅 / 喷绘布

```text
将图 1 延展为超宽横版并印刷到图 2 上下两条横幅的布面区域。最大限度保留 Logo、主标题和核心图形，左右只用主视觉背景纹理自然延展；不横向拉伸主体。两条横幅应呈现同一活动视觉在浅色和深色材质上的合理效果。设计必须跟随布面下垂、拉扯与褶皱产生自然形变，保留四角绑绳、布边、高光和阴影。
```

## 02｜落地道旗 / L 形旗

```text
把图 1 延展成窄竖版道旗设计，应用到图 2 的每一面旗布。各旗使用同一套完整设计的重复展示，不拆成三联画；Logo 放上部，核心图形放中部，必要文字精简置于下部。图案随旗布轻微卷曲与垂坠自然变形；保留黑色旗杆、横杆、底座及原有间距，旗杆不得被染色或覆盖。
```

## 03｜竖版易拉宝

```text
将图 1 应用到图 2 易拉宝的竖向画面中。按画面比例等比缩放，尽量保留完整主标题、Logo、主图形与底部信息；比例不足时只延展背景，不拉伸人物、文字或 Logo。贴图边缘准确落在上下夹杆之间，保留金属顶部横杆、底部底座、支脚、画布轻微反光和投影。
```

## 04｜落地导视立牌

```text
将图 1 转化为简洁的会议导视系统，应用到图 2 立牌正面。保留主视觉的品牌色、Logo 与核心纹样；只突出【待补：目的地/主会场】和【待补：左/右/上箭头方向】。文字必须居中清晰、远距离可读，箭头方向绝对准确。设计随立牌透视贴合，保留立牌厚度、侧面、底座、边缘高光和接触阴影；不改变样机角度与背景。
```

## 05｜三角桌牌 / 代表名桌牌

```text
将图 1 延展为横向桌牌版式，贴到图 2 面向镜头的可见纸面。保留品牌色、Logo 和一处简洁核心纹样；主要信息仅显示【待补：姓名/代表名/嘉宾名】，字体大、居中、远距离可读。不要把竖版主海报缩小塞入桌牌。设计严格跟随三角折纸透视，保留顶部折线、纸张厚度、背面、底边、桌面接触阴影与原有背景。
```

## 06｜圆形桌号牌

```text
把图 1 的品牌色、Logo 和核心背景纹样应用到图 2 的圆形号码牌。突出白色编号【待补：桌号，例如 01 / 02】；Logo 位于上方、号码居中，不放长段正文。图案服从圆形裁切并保持方向端正，保留夹具、细杆、金属底座、高光、反射和原有摆放角度。
```

## 07｜双联入场券

```text
将图 1 延展为横向活动票券，印刷到图 2 两张票的正面。保留 Logo、主视觉核心图形和品牌色，并建立清晰的信息层级：活动名【待补】、日期【待补】、地点【待补】、票号【待补】。虚线撕口两侧保持连续协调，重要文字不得压到撕口或半圆缺口。保留纸张厚度、透视、打孔虚线、缺口和投影。
```

## 08｜车辆通行证

```text
将图 1 延展为横向车辆通行证，应用到图 2 上下两张卡片。上方卡片为正面，突出“车辆通行证”、活动名【待补】、日期【待补】和编号【待补】；下方卡片为背面，延续品牌背景并预留车辆信息或注意事项区。两面属于同一视觉系统，但不重复堆砌整张海报。保留图 2 的底板、间距和正视角度，卡片边缘整齐。
```

## 09｜挂绳胸卡 / 嘉宾证套装

```text
把图 1 延展为会议证件系统并应用到图 2 所有胸卡的正反面。统一使用图 1 的品牌色、Logo、核心纹样和字体气质，并通过辅助色区分【待补：嘉宾 GUEST】、【待补：媒体 MEDIA】、【待补：工作人员 STAFF】、【待补：VIP】等类型。正面仅保留证件类型、照片占位区、姓名【待补】与职务【待补】；背面延续品牌图形并减少文字。所有胸卡版式对齐、信息清晰，不把整张海报缩小塞入卡片。保留挂绳、卡扣、铆钉、塑料卡套、阴影和背景；只替换卡片印刷面，挂绳可随证件辅助色变化。
```

## 10｜箭头造型手举牌

```text
基于图 1 设计箭头造型活动手举牌，完全沿用图 2 的箭头外轮廓和圆角切线。保留 Logo、主视觉核心图形和品牌色；主要文字为【待补：指引语】，箭头方向必须为【待补：左/右/上】。核心信息避开轮廓收窄处，版面简洁、远距离可读。输出正视、轮廓完整的成品，保留图 2 的背景处理，不改变箭头形状。
```

## 11｜长柄接机牌 / 引导牌

```text
将图 1 延展为横向引导牌，贴到图 2 长柄牌的矩形面板。保留 Logo、品牌色和一处核心纹样；主要文字为【待补：接机/分组/会场信息】，字号大、对比强、远距离可读。贴图严格跟随面板透视，保留金属包边、背部连接件和长柄；图案不得覆盖到支架上，不改变背景和阴影。
```

## 12｜手持邀请卡

```text
将图 1 延展为横向卡片，印刷到图 2 手中卡纸的正面。保留 Logo、品牌色、核心纹样和简洁标题【待补】；四周保留安全边距，不把重要信息裁出纸张。图案随卡片角度准确透视，保留纸张纤维、边缘厚度、手指遮挡、原有手部姿势和背景；不要改变手指数量或肤色。
```

## 13｜麦克风方形麦标

```text
从图 1 提取 Logo、品牌主色和最具识别度的简洁纹样，应用到图 2 麦克风中部方形麦标的四个可见面。正面以 Logo 为主，不放长标题或小字；侧面使用纯品牌色或连续纹样。设计必须随立方体透视转折，保留塑料高光、棱角、网头、手柄和反射；任何图案不得覆盖金属网头或手柄。
```

## 14｜演讲台正面面板

```text

```

## 15｜圆形纪念盘




## 可选质量约束

若模型易跑偏，在完整提示词末尾追加以下与当前物料有关的句子：

```text
不要重新设计主视觉，不要改变 Logo，不要生成乱码，不要把文字改成装饰线条。所有印刷图案只出现在指定可印刷面；支架、五金、绳带、手部、瓶盖、麦克风、纸巾和背景保持原样。
```

```text
主视觉比例与物料比例不一致时，优先延展背景和减少次要元素；不得横向或纵向拉伸任何 Logo、人物、数字和文字。
```
