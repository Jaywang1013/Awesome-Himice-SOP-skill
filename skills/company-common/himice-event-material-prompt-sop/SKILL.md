# Himice 延展物料提示词技能

用户必须提供一张活动主 KV 图（图 1）。本技能从内置样机中选取物料参考图（图 2），生成“将图 1 设计替换到图 2 可印刷面”的提示词；交付物是选中的样机和提示词，而不是直接冒充可印刷的设计源文件。

## 输入与边界

- 必需输入：活动主 KV 图片；目标物料名称或使用场景。若用户只给 KV，先询问需要哪些物料；可根据场景给出 3–5 项建议，但不擅自批量选择全部。
- 可选输入：活动名称、必须准确出现的文字/编号/日期、箭头方向、证件类型、成品用途、背景偏好。
- 内置样机是带既有活动画面的效果参考，不是空白刀版。将它们只用作物体结构、构图、镜头、材质和光影的参考；必须完整替换可印刷面上已有的标识、文字和图案。
- 图像生成结果只用于视觉预览。含中文、姓名、二维码、编号、日期或严格出血尺寸的物料，必须在设计软件中复核并制作生产文件；不得把 AI 生成图当作印刷定稿。
- 不擅自添加、改写或虚构主 KV 中没有的 Logo、活动事实、客户名称或人物信息。用户未提供必填文案时，使用 `[待补]` 占位，而不是猜测。

## 工作流程

1. 识别用户要做的物料。按[物料目录](references/material-catalog.md)选择最匹配的样机；同一物料有多版样机时，仅在用户有明确偏好时选择对应版本，否则给出推荐并说明。
2. 读取所选物料的[提示词配方](references/prompt-recipes.md)，不要读取无关物料的配方。配方中的方括号由用户输入替换；未提供则保留 `[待补：字段]`。
3. 将[通用双图前缀](references/prompt-recipes.md#通用双图前缀)与所选物料配方合并成一段完整提示词。明确上传顺序：图 1 = 新活动主 KV，图 2 = 内置样机。
4. 每个物料独立输出：物料名称、选择原因、样机文件链接、适配策略、完整提示词、印前注意事项。用户一次需要多项物料时，逐项输出，不把多个物料混在同一个生成指令里。
5. 交付前核验：新 KV 应只出现于可印刷面；样机原有结构不变；所有明确文案均逐字保留或已标为需后期覆盖；输出画幅与图 2 一致。

## 场景速配

| 用户表述 | 优先推荐 |
| --- | --- |
| 签到、会务座席、嘉宾接待 | 桌牌、桌号牌、胸卡、入场券、手持邀请卡 |
| 动线、入口、会场指引 | 悬挂横幅、道旗、易拉宝、导视立牌、箭头手举牌、长柄引导牌 |
| 舞台或发言 | 麦标、演讲台 |
| 礼品、茶歇、餐饮 | 纪念盘、瓶装水、纸巾盒、礼盒 |
| 打卡区、陈列区 | 圆柱陈列台，以及现场导视物料 |

不要把“同系列视觉”理解为把整张海报机械缩小到任何表面：大画面采用原样贴图，信息载体采用版式延展，小面积或曲面物件只提取品牌元素。具体规则见所选配方。

## 固定交付格式

````markdown
### [物料名称]

- 样机：`assets/mockups/<实际文件名>.png`（替换为物料目录中对应的真实文件链接）
- 适配策略：原样贴图 / 版式延展 / 品牌提取
- 上传顺序：图 1 = 用户的活动主 KV；图 2 = 上述样机。

**可直接使用的提示词**
```text
[通用双图前缀 + 对应物料配方]
```

**印前提醒**：[…]
````

用户若明确要求实际生成延展图，可在确认主 KV 与所选样机后，将同一双图提示词交给图像生成工具执行；仍需交付上述印前提醒，且不能承诺文字和二维码完全准确。
