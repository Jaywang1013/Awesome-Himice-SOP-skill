# Himice 项目预算表

仅在用户明确调用 `/himice-budget-process` 后执行。先读取 `${CLAUDE_SKILL_DIR}/references/budget-rules.md`，默认复制 `${CLAUDE_SKILL_DIR}/assets/【项目预算表】鱼鹰号+活动名称.xlsx`；用户上传的同结构最新版模板优先。

## 开始前

一次性收集：会议名称、会议人数、执行起止时间、公司参与人数、会议负责人、会议报账人。人员补助还须确认正式员工、试用期、实习生、M 级管理层人数和天数。缺项标 `[待确认]`，不得猜测。

## 制表

1. 读取报价的板块、明细、规格、单价、数量、次数、小计、成本和代付标记，并先复核报价总额。
2. 将明确“会议服务商代付”的酒店会场、酒店住宿、酒店餐饮、机票、动车放入五项专用行；茶歇不进入代付基数。默认服务费为 6%，但报价明确费率或金额时优先采用明确值。
3. 其他项目按客户报价顺序写入普通明细；连续同板块纵向合并第一列。成本未提供时可临时镜像收入，但必须标为待采购核价。
4. 报价未出现的普通明细清空或整行删除；新增项目在同板块插入行，并复制邻行样式、公式、数据验证及小计范围。固定代付、操作费用和汇总区不删除。
5. 黄色仅标记需提取现金的物料预计成本总价；不可标黄代付、服务费、税费或单价/数量/次数。现金属性不明时先询问。
6. 按参考规则填写默认餐饮、交通、住宿和人员补助；保持人民币两位小数、所有公式、格式、冻结窗格和合并关系。

## 验收与交付

复算单项、板块小计、五项代付基数、服务费、税费、预计收入、预计成本和毛利；检查无重复计入、公式错误和格式破坏。渲染主表复核后交付 `.xlsx`，同时说明镜像成本、代付费率来源及待确认输入。

实际费用报销请调用 `/himice-operating-expense-reimbursement-process`，不得直接以预算金额代替实际凭证金额。
