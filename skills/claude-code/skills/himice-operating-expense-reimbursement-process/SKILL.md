# Himice 操作费用报销

仅在用户明确调用 `/himice-operating-expense-reimbursement-process` 后执行。先读取 `${CLAUDE_SKILL_DIR}/references/operation-expense-rules.md`。默认复制 `${CLAUDE_SKILL_DIR}/assets/【模板】项目操作收支明细表.xlsx`；用户上传同结构最新版模板时优先使用。

## 范围

当前模板只填写工作表 `表1 (2)`（显示标题“项目操作收支明细表”）中的对应付款区。不得新增、删除、重排工作表，也不得修改下拉选项、样式、小计或资金汇总公式。此流程仅整理事实，不替代财务审批、税务判断或付款。

## 录入

1. 提取每份凭证的真实日期、商户/平台、金额、起终点、付款证据、发票和经手人；同一交易的发票、行程单和支付凭证先匹配去重。
2. 行程单有多笔行程时必须逐笔写行，金额取各行程明细，并与关联发票价税合计核对。备注格式为：滴滴 `滴滴：<出发地>-<目的地>`；货拉拉 `货拉拉：<出发地>-<目的地>`。
3. 微信/支付宝/零钱、备用金或个人垫付且有截图的写“现金支出”；信用卡写“刷卡支出”；银行转账写“已转帐款项”；无法确认则标 `[待确认]`。
4. 填写序号、日期、下拉类型/明细、摘要、单价、数量、次数、发票、备注和经手人。金额列必须为 `单价×数量×次数` 公式。关联发票已提供时，在发票列选择 `√`；仅截图或未提供发票时不勾选。
5. 客运、货运、机票、动车和加油一般归 `操作费用/交通费`；餐食归餐饮费；印刷、花卉等归物料费；用途不足的便利店支出归其他操作费并在备注说明。酒店或会议服务商代付不自动作为个人报销。
6. 行数不足时，仅在对应付款板块提示行上方插入行，并继承格式、下拉、金额公式及小计范围。

核对拆分与去重、发票勾选、付款区小计和总计；不得改变原始凭证金额。渲染唯一工作表检查格式和下拉项，未提供制度规则的审批、税务或时限事项标 `[待财务确认]`。
