> 控件类型的通用操作手法一律指回这里。

## 一、控件类型总表

| 控件类型 | 典型字段 | 识别特征 | 操作手法 |
| --- | --- | --- | --- |
| 只读 | 申请人、核算部门、操作公司、付款公司、大写金额 | 灰底、点不进去、无输入光标 | **不要尝试编辑**；只核对其值是否正确，异常即停 |
| 自由文本 | 备注、收款单位、开户行、账号、金额 | 有光标、可输入 | `gui.py type`（Unicode）；点**右半空白区**才聚焦 |
| 拼音联想 | 项目负责人、鱼鹰号、成本费用类别、客户名称 | 打字母出候选下拉 | `gui.py keys "拼音"` → 等候选 → `gui.py key "数字"` 选字；**不能直接打中文** |
| 下拉单选 | DC 付款、印章类型、文件管控分类 | 点开后小列表 | 点开 → **悬停到列表项上**再滚 → 点选项；选项通常 ≤3 |
| 日期浮层 | 约定付款时间、申请日期 | 弹出第二层日历，常被窗口底边截断 | 点字段 → 光标移到**日历外**滚动让浮层上移 → 点日期 |
| 附件 | 合同/发票/结算单/用印文件 | 「+ 添加附件」按钮 | `+ 添加附件` → `选择本地文件上传` → 面板 `Cmd+Shift+G` 输路径 → `打开` → 上传面板点「确定」 |
| 人员选择器 | 项目负责人、抄送人 | 点 `+` 弹面板，默认组织架构树 | 用面板**顶部搜索框**搜姓名；跨部门搜不到先把范围切到公司级 → 点结果行 → 点窗口右下角「确定」 |

## 二、按控件类型的通用校验

- **只读字段**：必须与预期一致（如「核算部门」未精确到部门需人工修正），不一致就停下问，不改只读值。
- **自由文本**：填完截图复核，重点看**小数点、千分位、首字符**是否丢失。
- **拼音联想**：选字后立刻回读字段值；出现"拼音+数字"乱码要清空重填（清空用逐字退格）。
- **下拉单选**：确认选中的是**目标选项文本**而不是同名前缀项。
- **日期浮层**：落到目标日后回读一次日期，避免点偏到相邻日。
- **附件**：确认**只有一份**、文件名与要求一致；看不见条目时不要重复上传。
- **人员选择器**：确认选择结果计数（如「已选择 1/5」），避免多选/漏选。

## 三、写字段映射时的约定

`references/field-mapping.md` 的「控件类型」列必须用上表的标准叫法（只读 / 自由文本 / 拼音联想 / 下拉单选 / 日期浮层 / 附件 / 人员选择器），这样读者能直接对上本文件的手法，不必在流程文档里重复解释。
