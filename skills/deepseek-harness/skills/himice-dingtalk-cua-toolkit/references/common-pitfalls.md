# 通用跨模板技术坑（钉钉 Qt 自绘客户端）

> 本文件是**单一来源**。所有 `himice-dingtalk-*` 流程 skill 的 `references/pitfalls.md`
> 只写「本流程专属」的坑，通用技术坑一律指向这里，不重复写。
>
> 坐标系与路径一律来自工具包 `config.env`，**本文档不含任何具体坐标值**（现 look 现点）。

## A. 焦点与窗口

| # | 症状 | 原因 | 处置 |
| --- | --- | --- | --- |
| A1 | 点了输入框光标不进、点按钮面板不弹，像卡住 | **焦点被别的窗口抢走**（DSH 自身窗口会反复置顶） | 先 `gui.py focus` 重新聚焦钉钉再点一次；**不要先去调坐标**，焦点错的概率远高于坐标错 |
| A2 | 截图拍到锁屏时间、或别的窗口内容 | 屏幕已锁 / 前置窗口错 | 开工前 `caffeinate -d -i -t 7200 &`；每次截图前确认目标窗口在最前 |
| A3 | AX/无障碍读不到任何字段 | 钉钉是 Qt 自绘，控件树是空壳 | 放弃 AX，一律走截图 + OCR；AX 只用来置顶窗口 |

## B. 截图与 OCR

| # | 症状 | 原因 | 处置 |
| --- | --- | --- | --- |
| B1 | 带区域的 `screencapture -R` 报 `could not create image from rect` | 部分 macOS 版本区域截图异常 | 改用**全屏截图 + `sips` 裁切**（工具包 `look*.sh` 已按此实现） |
| B2 | OCR 坐标与点击位置差一截 | Retina 倍率换算错 | 屏幕点 = 像素 / `config.env` 的 `SCREEN_SCALE`；`look*.sh` 输出已是屏幕点，直接喂 `gui.py` |
| B3 | 部分字段 OCR 认错（形近字） | 字形/字重接近 | 关键值（金额、账号、鱼鹰号）必须**截图局部放大复核**，不靠一次 OCR 定论 |

## C. 输入

| # | 症状 | 原因 | 处置 |
| --- | --- | --- | --- |
| C1 | 直接打中文进不去，字段里出现拼音字母 | 该字段是**拼音输入法式**控件 | 打拼音 → 等候选 → 按数字键选字（`gui.py keys "pinyin"` + `gui.py key "1"`） |
| C2 | 选字后字段出现 `xxx2` 这类乱码 | 候选未弹出就按了数字键 | 每次选字后立刻复核字段值；错了清空重来（逐字退格，`Cmd+A` 在本表有副作用） |
| C3 | 金额只能输整数、小数点丢了 | 真实键码（`keys`）的键码表**不含小数点** | **含小数点的数值一律用 Unicode 方式**（`gui.py type "1234.56"`） |
| C4 | 长文本首位特殊字符丢失（如 `(厦门)XK…` 少了左括号） | 长文本首字符偶发丢失 | 填完局部放大读一遍开头；缺了用光标移行首补，别整段重输 |
| C5 | 输入框能点但没聚焦 | Qt 自绘框的可点区在**右侧空白区**，点左侧占位文字无效 | 点输入框**右半部分空白区**再输入 |

## D. 控件操作

| # | 症状 | 原因 | 处置 |
| --- | --- | --- | --- |
| D1 | 下拉列表滚不动，表单却在滚 | 滚轮作用于表单而非列表 | 把鼠标**悬停在列表项上**再滚 |
| D2 | 日期日历只露出标题行、其余被窗口底边切掉 | 日历是**第二层浮层**，不会自动上移 | 把光标移到**日历外面**再滚，浮层随表单整体上移；在日历内滚无效 |
| D3 | 面板里选好了却找不到「确定」 | 确定/取消**在窗口右下角**，不在浮层内 | 取消在左、确定在右，位置固定在窗口右下区域 |
| D4 | 附件上传面板里一片空白 | **属正常渲染**，不是失败 | 直接点面板右下角「确定」；不要因看不见就重复上传（会产生重复附件） |
| D5 | 想删附件却弹出预览（WPS） | 「预览 / 删除」共用同一行 y，仅靠 x 区分 | `Cmd+W` 关闭预览（`Esc` 无效）；悬停后先确认按钮 y 与目标文件行对齐 |
| D6 | 点「+ 添加附件」没反应 | 可点区从文字**左侧**开始，点文字右端落在框外 | 按 OCR 位置直接点，不要凭"文字更宽"往右加偏移 |
| D7 | 附件名与原文件不符 | 钉钉取**文件名**而非完整路径 | 用副本可以，但**必须保留原始文件名**；含全角 `【】（）` 的路径可正常上传 |
| D8 | 浮层展开后盖住下方目标字段 | 浮层向下展开 | 先关掉浮层，或滚动让目标字段离开浮层区域再操作 |
| D9 | 人员选择器里搜不到人 | 选择器**默认作用域是本部门** | 先把面板顶部组织范围切到公司级再搜姓名 |

## E. 草稿与滚动

| # | 症状 | 原因 | 处置 |
| --- | --- | --- | --- |
| E1 | 打开表单自动带着上次的内容 | 一个模板**只保存一份未提交草稿** | 需要空表就点「清除内容」；**覆盖前先把旧草稿字段写成快照文件**（本地，不入库） |
| E2 | 点了「清除内容」仍有字段残留（实测「项目负责人」会残留） | 清除不覆盖全部字段 | 清除后**逐字段复核**，残留项手工改掉 |
| E3 | 滚轮转了但表单位置不变 | 光标不在表单区域内 | 把光标移到**表单区域内**再滚 |
| E4 | 底部字段看得见却点不到 | 字段贴近窗口底边，点击区被裁掉 | 先把该字段**滚到屏幕中部**再点 |
| E5 | 模板搜索点错，表单结构对不上 | 搜索结果**横向并排**，同族模板相似 | 点之前核对模板**全名与括号内公司限定**；进错立即退出，不要将错就错 |
| E6 | 模板搜索框点了不聚焦 | 点在了搜索框可点区外 | 改点文本框内**靠左**位置 |

## F. 输入方式如何选（决策规则）

1. **含中文/小数点/全角符号/长串** → `gui.py type`（Unicode 方式）
2. **拼音联想字段**（项目负责人、鱼鹰号、成本费用类别、客户名称等） → `gui.py keys "拼音"` + 数字键选字
3. **纯 ASCII 且不含小数点**（编号、账号等） → 可用 `keys`（真实键码更稳），但填完必须复核
4. **任何"填完就信"的行为都禁止**：填完必须截图复核一次

## G. 无法自动化的边界

- 钉钉群机器人**只能单向发消息，读不了审批实例状态**：当前节点/卡在谁只能由用户告知或截图
- 提交后**撤回需人工**：机器人不自动撤回
- 钉钉改版即失效：坐标与控件形态都要现验
