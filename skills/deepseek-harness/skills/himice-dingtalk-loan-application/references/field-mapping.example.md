# 本机默认值模板 · 项目借款单

> **配对约定**：本目录下 `field-mapping.md` 与 `field-mapping.local.md` 是**一对**——
> `field-mapping.md` 放**结构**（字段名、必填、控件类型、取值来源），入库共享；
> `field-mapping.local.md` 放**本机实际值**（人名、公司、部门、账户、别名表），只存本机、不入库。
>
> **用法**：把本文件复制为同目录下的 `field-mapping.local.md`，按本机实际情况补全。
> `.local.md` 已被仓库 `.gitignore`（`*.local.md`）覆盖，**不会进仓库**；本 `example` 文件只含占位符，可入库。
>
> 这里放的是"每次都要填、但基本不变"的值，以及**含个人/客户信息的对照表**。
> 凡涉及人名、账号、项目编号，一律只写在本文件。

## 二、鱼鹰号别名表

用于把口头简称匹配到完整项目串（格式：`（城市）编号 项目全称`）。

| 常用简称 | 完整鱼鹰号 | 备注 |
|---|---|---|
| `<简称A>` | `（<城市>）<编号> <项目全称>` | 客户：`<客户简称>` |
| `<简称B>` | `（<城市>）<编号> <项目全称>` | 客户：`<客户简称>` |

**匹配优先级**：精确编号 → 全称包含 → 简称包含 → 拼音首字母 → 人工兜底。
**多义时回问发起人，不猜。**

> 提醒：鱼鹰号里 `（城市）` 是**项目编号前缀**，与「项目执行地点」不是一回事。

借款收款人由发起人当次指定。本表仅用于**减少重复询问**，**任何情况下都不得推测或沿用历史值**。

| 收款人（角色） | 开户行 | 银行账号 | 备注 |
|---|---|---|---|
| `<收款人A 姓名>` | `<开户行全称>` | `<账号>` | 需发起人当次确认 |

> **硬规则**：

> - 本表**绝不进仓库**；本 example 文件中该表**只放占位符**

## 四、预算表取数锚点

| 用途 | 位置 | 说明 |
|---|---|---|
| **借款金额** | 用款申请表 **`C25`**（现金小计） | 只借现金那一档 |
| 自校验 | `C21 小计 = C23 待转帐 + C24 刷卡 + C25 现金 + …` | 各档之和应等于小计 |
| 项目名称 | 项目预算表会议名称（常见 `B2`） | 同预算审批单 |

> ⚠️ 用款申请表**工作表名可能带尾随空格**，读取时须原样匹配，否则报 `KeyError`。
> ⚠️ 档位行号可能随项目变化，取数前先核对 `C25` 所在行标签确为「现金」。
