# Himice 钉钉项目借款单代填

通过桌面 GUI 自动化在**用户已登录的钉钉客户端**中代填审批表单。
本技能负责**填到提交前为止**，提交动作一律由人工确认后执行。

> 依赖共用工具包 `himice-dingtalk-cua-toolkit`（截图 / OCR / 点击 / 输入 / 窗口基准配置）。
> 本技能**不复制**工具包内的脚本，只引用；使用前先按工具包的 `config.env.example` 配好本机参数。

## 适用场景

- 项目需要**备用金**（现金支出无法走对公转账的部分），在钉钉发起借款
- 已在工作区拿到**项目预算表**（含用款申请表）
- 本技能只覆盖「项目借款单（厦门）」模板

> ⚠️ 搜索结果里「项目借款单（厦门）」「非项目采购借款」「借款申请」名称相近、**横向并排**出现，字段结构完全不同。**点错会填错整张表**，选定前先核对模板全名与括号内的公司限定。

## 前置条件

1. **工具包就绪**：`himice-dingtalk-cua-toolkit` 已安装，`config.env` 已按本机填写
2. **系统权限**：辅助功能 + 屏幕录制均已授予 DSH 客户端
3. **屏幕常亮**：开始前启动 `caffeinate`
4. **本机默认值**：复制 `references/field-mapping.example.md` 为 `field-mapping.local.md`，补全默认申请人、部门、所属公司、鱼鹰号别名表、**收款人银行账户对照表**（含个人账户信息，只存本机）
5. **收款人已明确**：收款人与银行账号**必须由发起人明确提供**，不得沿用历史值或猜测
6. **用户在场**：操作期间用户不能使用电脑，且每次交互前需重新聚焦钉钉窗口
7. **唯一草稿**：该模板**只保存一份未提交草稿**，填新单会覆盖旧草稿

## 逐步操作

### 1. 读预算表取借款金额（**先于一切界面操作**）

借款金额取自项目预算表的**用款申请表**：

| 用途 | 位置 | 说明 |
|---|---|---|
| **借款金额（元）** | 用款申请表 **`C25`**（现金小计） | **只借现金那一档** |
| 项目名称 | 项目预算表会议名称（常见 `B2`） | 同预算审批单 |
| 项目负责人 | 发起人指定 | — |

**为什么是现金小计**：用款申请表把用款拆成 `已转帐 / 待转帐 / 刷卡 / 现金` 几档。待转帐走对公付款，**现金支出无法转账，才需要先借备用金**。可自校验：

```
C21 小计 = C23 待转帐 + C25 现金 + …（各档之和）
```

要点：

- **不要**用操作费用小计或其他金额替代借款金额——两者口径不同
- 工作表名可能带**尾随空格**（如 `预算-用款申请表  `），用脚本读取时须**原样匹配**，否则报 `KeyError`
- 取数后先核对 `C25` 所在行的标签确是「现金」，再取值

### 2. 打开表单

1. 聚焦钉钉窗口
2. 左侧导航「工作台」→「OA审批」
3. 顶部「请输入审批单名称」搜索框输「借款」→ 结果**横向并排三项**，点**最左的「项目借款单（厦门）」**
   - 搜索框需点**文字右侧**才聚焦
4. 表单打开后若提示「已自动填写上次未发布草稿内容」，按需点「清除内容」

### 3. 逐字段填写

字段清单与取值见 `references/field-mapping.md`。注意点：

- **借款申请人 / 所属公司 / 核算部门** → 只读，按本机默认值核对
- **项目负责人** → 人员选择器；**面板默认是组织架构树**，须用面板顶部搜索框搜姓名
- **项目名称（鱼鹰号）** → 自由文本，Unicode 方式整串输入
- **借款金额** → 自由文本，**必须用 Unicode 方式输入**（键码表无小数点）；填完用**大写自动值反查**
- **收款人姓名** → 人员选择器（同项目负责人用法）
- **收款人银行账号 / 开户行** → 自由文本，由发起人提供，**逐位核对**
- **关联审批单** → 非必填，无关联时留空

### 4. 上传附件

**附件（借款明细）** 上传项目预算表。

- 走「添加附件 → 选择本地文件上传」，可用 `Cmd+Shift+G` 输完整路径
- **附件名取文件名本身**：短路径副本必须**保留原始文件名**
- 上传面板**显示空白是正常的**，不要当失败重复上传；点右下角「确定」后回写

### 5. 提交前验证清单

- [ ] 模板确为「项目借款单（厦门）」（**不是**非项目采购借款 / 借款申请）
- [ ] 借款申请人、所属公司、核算部门与默认值一致
- [ ] 项目负责人为本项目实际负责人
- [ ] 项目名称（鱼鹰号）与预算表一致
- [ ] 借款金额 = 用款申请表 `C25`（现金小计）；**已用大写反查**
- [ ] 借款金额**未**误用操作费用小计或其他口径
- [ ] 附件（借款明细）已上传项目预算表，且**附件名正确**
- [ ] 收款人姓名与发起人指定一致
- [ ] 收款人银行账号、开户行与发起人提供一致（**逐位核对**）
- [ ] **未点提交**，已交人工确认

## 失败与回退

- **误触附件预览**（弹出 WPS 预览窗口）：`Esc` 无效，用 `Cmd+W` 关闭
- **点错模板**：立即关闭标签页重开，不要在错模板上继续填
- **草稿被覆盖**：该模板只有一份草稿，填新单前先把当前字段值快照到工作区
- **字段点不动**：绝大多数是焦点被抢，先重新 `focus` 再点
- **详情见** `references/pitfalls.md`
