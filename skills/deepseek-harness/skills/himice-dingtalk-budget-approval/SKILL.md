# Himice 钉钉项目预算审批单代填

通过桌面 GUI 自动化在**用户已登录的钉钉客户端**中代填审批表单。
本技能负责**填到提交前为止**，提交动作一律由人工确认后执行。

> 依赖共用工具包 `himice-dingtalk-cua-toolkit`（截图 / OCR / 点击 / 输入 / 窗口基准配置）。
> 本技能**不复制**工具包内的脚本，只引用；使用前先按工具包的 `config.env.example` 配好本机参数。

## 适用场景

- 项目立项后需要走预算审批，已在工作区拿到**项目预算表**
- 同批材料通常还包含**预估协作人审批表**（模板会要求作为附件二上传）
- 本技能只覆盖「项目预算审批单（厦门）」模板；相邻模板字段结构不同，**不可照搬**

## 前置条件

1. **工具包就绪**：`himice-dingtalk-cua-toolkit` 已安装，`config.env` 已按本机填写（钉钉窗口基准、Retina 倍率、`TMP_DIR`）
2. **系统权限**：辅助功能 + 屏幕录制均已授予 DSH 客户端（缺任一，截图或点击会静默失败）
3. **屏幕常亮**：开始前启动 `caffeinate`，否则锁屏后截图只拍到锁屏画面
4. **本机默认值**：复制 `references/field-mapping.example.md` 为 `field-mapping.local.md`，补全默认负责人、操作公司、部门、客户全称、鱼鹰号别名表；**该文件已在 `.gitignore` 中，只存本机**
5. **预算表可读**：`.xlsx` 直接读；注意工作表名可能带尾随空格
6. **用户在场**：操作期间用户不能使用电脑，且每次交互前需重新聚焦钉钉窗口
7. **唯一草稿**：该模板**只保存一份未提交草稿**，填新单会覆盖旧草稿——覆盖前先按「失败与回退」里的快照法留档

## 逐步操作

### 1. 读预算表并取数（**先于一切界面操作**）

从项目预算表取以下单元格（工作表名以实际为准，常见为 `项目预算表-项目决算表`）：

| 用途 | 单元格 | 说明 |
|---|---|---|
| 项目收入预算 | `F64` | 预计收入总计 |
| 项目成本预算 | `F65` | 预计成本总计 |
| 操作费用金额 | `J52` | 操作费用**小计**（不是明细行） |
| 日程安排 | `B3` | 形如 `2026/9/8-2026/9/9`，拆成执行/结束时间 |
| 会议名称 | `B2` | 即鱼鹰号 + 项目名称 |
| 会议人数 | `G3` | 供核对 |

要点：

- **毛利与毛利率不要填**，表单会自动计算
- 预算表的金额常为**长小数**（未四舍五入），填表时按两位小数呈现即可；**以预算表的收入、成本为准**
- 单元格位置的**行号可能随项目变化**，取数时先确认 `F64/F65/J52` 三个锚点单元格仍是「预计收入/预计成本/操作费用小计」，不要盲取
- 工作表名可能带**尾随空格**（如 `预算-用款申请表  `），用脚本读取时须原样匹配，否则报 `KeyError`

### 2. 打开表单

1. 聚焦钉钉窗口（工具包的 `focus`）
2. 左侧导航「工作台」→「OA审批」
3. 用顶部「请输入审批单名称」搜索框输模板名 → **点结果里正确的那一个**（同族模板会并排，见 pitfalls 通用坑）；搜索框需点文字右侧才聚焦
4. 表单打开后会提示「已自动填写上次未发布草稿内容」——如从空表开始，点右上角「清除内容」
   - ⚠️ 「清除内容」**不一定清干净**，实测「项目负责人」会残留上次的值，需逐字段核对

### 3. 逐字段填写

字段清单与控件类型见 `## 字段映射` 一节，完整字段表见 `references/field-mapping.md`。控件类型决定操作手法：

- **客户名称** → 拼音联想：打拼音 → 出候选 → 数字键选字 → **可能出二级列表**（先列具体分支，再列公司全称），选**公司全称**那一项
- **项目名称及编号** → 自由文本，Unicode 方式整串输入
- **执行/结束时间** → 日期浮层；若日历顶部有输入框，直接输入 `YYYY-MM-DD` 回车最快；无输入框时只能点翻月箭头（见 pitfalls）
- **执行地点 / 操作公司 / 部门** → 按本机默认值或无来源时回问
- **项目负责人** → 人员选择器：弹出面板**默认是组织架构树**，须用面板顶部搜索框搜姓名
- **项目类型** → 下拉单选（默认「差旅」，特殊情况按发起人说明）
- **收入 / 成本 / 操作费用 / 渠道费用** → 自由文本，**必须用 Unicode 方式输入**（键码表无小数点）
- **是否有预收款** → 下拉单选；选「否」时预收款金额与日期留空

### 4. 上传附件

- **附件一（预算、合同）**：项目预算表；**合同有则一并上传，没有就只传预算表**，不要为等合同而卡住
- **附件二（预估协作人审批表）**：预估协作人审批表（模板备注明确要求「新项目预算发起时请同时上传协作人业绩分配表」）

附件操作要点：

- 附件走「添加附件 → 选择本地文件上传」，可用 `Cmd+Shift+G` 输完整路径
- **附件名取文件名本身**：若用短路径副本，必须**保留原始文件名**，不要改名
- 含全角符号（`【】（）`）与中文的路径**可以正常上传**
- 上传面板**显示空白是正常的**，不要当失败重复上传；点面板右下角「确定」后文件才回写表单

### 5. 停机确认

填完所有字段、上传完附件后**停下**，把本单交人工确认，**不要点提交**。核对用 `## 提交前验证清单`。

## 字段映射

完整字段表（含必填、取值来源、控件类型、默认值来源、格式校验）见 `references/field-mapping.md`。速览：

| 分组 | 字段 | 控件类型 | 取值来源 |
|---|---|---|---|
| 项目信息 | 客户名称 | 拼音联想（可能二级列表） | 客户公司**全称** |
| 项目信息 | 项目名称及编号 | 自由文本 | 预算表会议名称 |
| 项目信息 | 项目执行/结束时间 | 日期浮层 | 预算表日程 |
| 项目信息 | 项目执行地点 | 自由文本 | 预算表 / 发起人确认 |
| 项目信息 | 项目操作公司 / 项目部门 | 只读 | 本机默认值 |
| 归属 | 项目负责人 | 人员选择器 | 本机默认值（**覆盖草稿残留**） |
| 归属 | 项目类型 | 下拉单选 | 默认「差旅」 |
| 金额 | 项目收入预算 | 自由文本（数字） | 预算表 `F64` |
| 金额 | 项目成本预算 | 自由文本（数字） | 预算表 `F65` |
| 金额 | 项目毛利预算 / 毛利率预算 | 自动计算 | **不手工填** |
| 金额 | 项目操作费用金额 | 自由文本（数字） | 预算表 `J52`（小计） |
| 金额 | 客户渠道费用 | 自由文本（数字） | 默认 `0` |
| 金额 | 是否有预收款 / 预收款金额 / 日期 | 下拉单选 + 自由文本 + 日期浮层 | 默认「否」，选否时后两项留空 |
| 附件 | 附件一（预算、合同） | 附件 | 项目预算表（+ 合同） |
| 附件 | 附件二（预估协作人审批表） | 附件 | 预估协作人审批表 |

> 只读/自动字段共 5 项（操作公司、部门、毛利、毛利率等），**不要尝试编辑**。
> 「操作费用金额」取**小计**行，不是明细行。

## 失败与回退

- **误触附件预览**（弹出 WPS 预览窗口）：`Esc` 无效，用 `Cmd+W` 关闭
- **草稿被覆盖**：该模板只有一份草稿，填新单前先把当前字段值快照到工作区再动手
- **字段点不动**：绝大多数是焦点被抢，先重新 `focus` 再点，不要先调坐标
- **详情见** `references/pitfalls.md`

## 提交前验证清单

逐条核对后再交人工确认：

- [ ] 客户名称是**公司全称**（不是联系人姓名）——R5
- [ ] 项目名称及编号与预算表会议名称完全一致——R2
- [ ] 执行/结束时间与预算表日程一致——R2
- [ ] 执行地点已按预算表或发起人说明确认；操作公司、部门与默认值一致——R10
- [ ] 项目负责人为本项目实际负责人（**已覆盖草稿残留值**）——R6
- [ ] 项目类型正确（默认差旅，特殊已说明）——R7
- [ ] 收入预算 = 预算表 `F64`；成本预算 = 预算表 `F65`——R1、R4
- [ ] 毛利/毛利率为**表单自动计算值**，未手工干预——R3
- [ ] 操作费用金额 = 预算表 `J52`（操作费用**小计**）——R1
- [ ] 客户渠道费用为默认值；是否有预收款、预收款金额/日期按规则填写——R8、R9
- [ ] 附件一已含预算表（有合同则一并）；附件二已含预估协作人审批表——R11、R12
- [ ] 两项附件的**附件名正确**（保留了原始文件名）——R13
- [ ] 备注按「默认无、特殊情况特殊说明」处理——R14
- [ ] **未点提交**，已交人工确认

> 每条末尾的 `R*` 对应 `references/business-rules.md` 中的硬规则编号，便于追溯与复核。
