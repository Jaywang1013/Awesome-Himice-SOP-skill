# 踩坑记录 · 项目预算审批单

组织方式：**症状 → 原因 → 处置**，不按字段组织。
分两节：**通用跨模板**（换任何模板都成立）与**预算审批单专属**。

> 团队规范：**具体屏幕坐标不进文档**。坐标随窗口位置、钉钉版本变化，一律靠"先 look 再 click"现取现用；
> 窗口基准（位置 / 尺寸 / Retina 倍率）作为可配置项放在工具包 `config.env`，不在本文件写死。

## 一、通用跨模板

完整通用坑位见付款技能的 `../../himice-dingtalk-payment-application/references/pitfalls.md`。以下是**预算审批单实际踩到**的部分：

### 1. 点击完全没反应

- **症状**：点了输入框，光标不进；点了按钮，面板不弹
- **原因**：**焦点被其他窗口抢走**——DSH 自己的窗口会反复置顶，绝大多数"点击失效"是这一条
- **处置**：先重新聚焦钉钉窗口再点。**不要先去调坐标**，坐标错的概率远低于焦点错

### 2. 「+ 添加附件」按钮要点文字左侧

- **症状**：点了「添加附件」，面板**完全不弹且无任何报错**
- **原因**：OCR 报出的是**文字中心**，但按钮框从文字**左边相当一段**才开始。对着文字右端点会落在框外
- **处置**：**按 OCR 给的坐标直接点**，不要凭"文字更宽"往右加

### 3. 悬停按钮的 y 必须与文件行对齐

- **症状**：想点附件的「删除」，却每次都弹出 WPS 预览窗口
- **原因**：附件行悬停后显示的 `预览 | 删除` **共用同一行 y**，靠 x 区分；y 用错行（例如用了上一行附件的 y）就会命中「预览」
- **处置**：**y 跟文件行严格对齐**；删除在右、预览在左，两者相距仅几十点

### 4. 误触 WPS 预览窗口后如何退出

- **症状**：附件预览弹出后 `Esc` 按了没用
- **原因**：预览是钉钉内嵌 WPS 窗口，不吃 `Esc`
- **处置**：用 **`Cmd+W`** 关闭，可直接回到表单

### 5. 附件上传面板显示空白

- **症状**：点「打开」后弹出上传面板，**面板内一片空白**，看不到文件条目
- **原因**：正常现象，不是失败
- **处置**：**不要**因此重复上传（重复会产生重复附件）；直接点面板右下角「确定」，文件随后出现在表单附件区

### 6. 直接打中文进不去字段

- **症状**：想输公司名，字段毫无反应或出现拼音字母
- **原因**：该字段是**拼音输入法式**控件（见 `field-mapping.md` 控件类型列）
- **处置**：打拼音 → 出候选 → 按数字键选字

### 7. 模板搜索结果默认横向排列

- **症状**：点搜索结果打开了**完全不相干的模板**
- **原因**：搜索框下方的结果**横向排列在同一行**，位置相近容易点错
- **处置**：点之前先确认模板全名；同族模板并排时格外小心

### 8. 模板搜索框点偏右不聚焦

- **症状**：在「请输入审批单名称」里输入，占位文字仍在，说明没聚焦
- **处置**：换位置重试（实测点**文字右侧**才聚焦）

### 9. 金额输入变成整数（小数点丢失）

- **症状**：输入 `12345.67` 实际显示 `1234567`
- **原因**：`type_ascii`（键码方式）的键码表**没有小数点**
- **处置**：金额、账号等含小数点的内容**一律用 Unicode 方式**（工具包 `gui.py type`）

### 10. 底部字段被窗口底边挡住

- **症状**：点底部的「请选择」下拉完全不弹
- **处置**：**先把该字段滚到屏幕中部再点击**；日历浮层被截断时，把光标移到**日历外**再滚动，浮层整体上移

### 11. 「清除内容」不一定清干净

- **症状**：点了「清除内容」，大部分字段空了，但**某个字段仍留着上次的值**
- **原因**：实测「项目负责人」会残留
- **处置**：清空后**逐字段核对**，特别是人员类字段

### 12. 一个模板只有一份草稿

- **症状**：填新单后，旧单的未提交内容不翼而飞
- **处置**：填新单前**先把当前草稿字段快照到工作区**（见 SKILL.md「失败与回退」）

## 二、预算审批单专属

### 13. 日期选择器有两条路径，视字段而定

- **症状**：点了「请选择」，日历弹出但**顶部没有输入框**，翻月箭头又找不到
- **原因**：部分日期字段的日历带输入框，部分不带
- **处置**：
  - **带输入框**（如项目执行时间）：`Cmd+A` 全选 → 输入 `YYYY-MM-DD` → 回车，最快
  - **不带输入框**（如项目结束时间）：只能点翻月箭头。箭头是**小图标，OCR 常读不到**，需裁切放大定位；点偏会误触年份选择器（弹出年份网格），此时 `Esc` 退回即可

### 14. 客户名称是拼音联想 + 二级列表

- **症状**：打拼音后候选里没有公司全称，选了第一项却填进了某个分支机构
- **原因**：客户字段是**两级**——先出公司名简称候选，选中后**再弹二级列表**列具体分支与公司全称
- **处置**：在**二级列表里选公司全称那一项**（通常排在分支之后）；若候选里没有全称，把拼音打全一些

### 15. 项目负责人是人员选择器，不是下拉

- **症状**：点「请选择」弹出了**组织架构树**（列公司/部门/人数），找不到人名
- **原因**：人员选择器面板**默认视图是组织架构**，不是人员列表
- **处置**：用面板**顶部搜索框**搜姓名 → 出候选 → 点击 → 右侧显示「已选择（n/1）」→ 点右下角「确定」
- **附注**：若误触了组织架构树的「下级」等按钮，`Esc` 或点「取消」退出即可

### 16. 毛利/毛利率看似要填，实际自动生成

- **症状**：填完收入后，毛利字段**直接显示成了收入的值**，看着像填错了
- **原因**：毛利 = 收入 − 成本，成本还没填时它与收入相等
- **处置**：**不要手工改**；填完成本后它会自动更新

### 17. 附件一、附件二各有独立的「添加附件」

- **症状**：点了「添加附件」，文件却挂到了**另一个附件位**下面
- **原因**：两个附件位各有一个按钮，纵向相邻
- **处置**：**看清按钮属于哪个附件位再点**；上传后核对文件是否挂在正确的那一栏
