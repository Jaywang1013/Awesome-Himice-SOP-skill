# 用印申请 · 字段映射（共享版）

> **本文件进仓库**，只放字段规则与判定依据，**不含任何客户数据、人名、金额、鱼鹰号**。
> 本机实际默认值（公司全称、部门、常用项目等）放 `field-mapping.local.md`（已被 `.gitignore` 忽略）。
> 业务口径硬规则见 `business-rules.md`；技术操作坑见 `references/pitfalls.md` 与 `himice-dingtalk-cua-toolkit`。

## 表单入口

钉钉 → 工作台 → OA审批 → 发起审批 → 搜「用印申请」。

## 字段全表

| # | 字段 | 必填 | 取值来源 | 处理方式 |
|---|---|---|---|---|
| 1 | 申请人所在公司 | 是 | 本机默认值 | 下拉选择，见 `field-mapping.local.md` |
| 2 | 申请人 | 是 | 自动带出 | 不填，核对为当前登录人 |
| 3 | 部门 | 是 | 自动带出 | 不填，核对为申请人所属部门 |
| 4 | 所用公司印章 | 是 | 同字段 1 | 下拉选择；**跨公司选「是」时本栏仍填本公司，不改** |
| 5 | （是/否）跨公司使用集团（海口）区域公司印章 | 是 | 默认「否」 | 特殊需要时用户告知改「是」，并触发字段 11、12 的确认 |
| 6 | 文件管控分类 | 是 | **用户告知** | 三选一，简写到正式值映射见下表 |
| 7 | 用印文件名称 | 是 | 拼接 | `鱼鹰编号 + 项目名称 + 上传文件名`，不重命名文件 |
| 8 | 文件接收单位 | 是 | **从合同读取** | 合同对方单位**全称**；读不出问用户 |
| 9 | 合同金额（元） | 是 | **从合同读取** | 按条款填阿拉伯数字，填完核对自动生成的大写 |
| 10 | 文件份数 | 是 | 用户上传份数 | **不是**合同约定的盖章份数，见 `business-rules.md` BR-03 |
| 11 | 印章类型 | 是 | 默认「公章」 | 可选：公章 / 合同章 / 法人章 / 财务章；特殊需要用户说明 |
| 12 | 电子印章 / 实体章 | 是 | 默认「实体章」 | **跨公司用印时必须问用户**，见 BR-02 |
| 13 | 是否需要原件（邮寄地址） | 是 | 默认「否」 | **跨公司用印时必须问用户**，见 BR-02 |
| 14 | 申请日期 | 是 | 提交当日或次日 | 日期浮层选择 |
| 15 | 备注 | 否 | 一般留空 | 特殊情况写明，如「用印文件为对方合同模板」 |
| 16 | 用印文件（附件） | 是 | 用户提供的文件 | 上传待盖章文件原件 |

## 文件管控分类：简写 → 正式值

| 用户简写 | 表单正式选项 |
|---|---|
| 对客合同 / 对客 | 对客销售合同（与客户签署的合同、PO单、客户采购订单） |
| 供应商合同 / 供应商 | 对供应商采购 |
| 投标 | 投标文件（标书、报价单、设计方案、投标授权书、投标入库文件等） |

**分类由用户告知，执行方不自行判断。** 详见 `business-rules.md` BR-01。

## 默认值速查

| 字段 | 默认 |
|---|---|
| 跨公司使用集团（海口）区域公司印章 | 否 |
| 印章类型 | 公章 |
| 电子印章 / 实体章 | 实体章 |
| 是否需要原件 | 否 |
| 申请日期 | 提交当日或次日 |
| 备注 | 留空 |

**默认值仅适用于非跨公司场景。** 跨公司选「是」时，字段 12、13 改为当场询问用户，不得默认。

## 不填 / 自动生成项

- **申请人、部门**：表单自动带出，只需核对。
- **合同金额的汉字大写**：填完阿拉伯数字后自动生成，**用作金额的反向校验**——大写与合同条款不符说明金额填错了。
