# Himice 钉钉用印申请（DSH）

先用 `skill` 工具加载 `himice-dingtalk-cua-toolkit`，本 skill 只写业务字段与判断，**不重复写坐标、OCR、输入框聚焦、下拉滚动、附件面板等技术坑**。

## 适用场景

对客销售合同、供应商采购合同、投标文件需要盖公司印章时，在钉钉 OA 审批发起「用印申请」。一次申请对应一份（或一组）待盖章文件。

**不适用**：付款申请（走项目付款流程，字段围绕资金而非文件）、用印后的电子签发起、审批节点的查询与催办（钉钉群机器人只能单向发消息，读不了审批状态）。

## 前置条件

1. 用户提供：**合同文件**（PDF/Word）、**鱼鹰编号 + 项目名称**、**文件管控分类**、**是否跨公司用印**。
2. 钉钉 Mac 客户端已登录且窗口保持前台，屏幕常亮，代填期间用户不操作电脑。
3. `himice-dingtalk-cua-toolkit` 的环境自检全部通过（截图权限、辅助功能、OCR、钉钉进程）。

## 必须当场问用户、不取默认值的两处

仅当「跨公司使用集团（海口）区域公司印章」选 **是** 时触发：

| 字段 | 为什么不能默认 |
|---|---|
| 电子印章 / 实体章 | 集团有独立规定，选错要重新走流程 |
| 是否需要原件 | 涉及是否邮寄合同原件到集团法务归档 |

其余字段按下方映射取默认值。

## 字段映射

完整字段表、默认值来源与判定依据见 `references/field-mapping.md`。要点：

- **用印文件名称** = 鱼鹰编号 + 项目名称 + 上传的文件名，三者拼接，不重命名文件
- **文件接收单位** 取合同对方单位**全称**，从签署栏或甲方抬头读取
- **合同金额** 从合同金额条款读取，填完后**用自动生成的汉字大写反向校验**
- **文件份数** = 用户上传的文件份数，**不是**合同约定的盖章份数（两者含义不同，易混）
- **文件管控分类** 由用户口头告知，不自行判断

## 执行流程

1. **识别合同** — 读合同，提取对方单位全称、合同金额、份数。读不出就问用户，**绝不臆造**。输入：合同文件；动作：转 Markdown 后按条款定位；易失败点：扫描件需 OCR、多份合同金额需逐份核对。
2. **补齐字段** — 拼用印文件名称、定管控分类、确认是否跨公司。输入：鱼鹰号+项目名称、管控简写；动作：按映射表组装；易失败点：鱼鹰号前缀丢失、项目名误用简称。
3. **钉钉填单** — OA审批 → 发起审批 → 用印申请。输入：字段映射结果；动作：清除旧草稿后逐字段填；易失败点：见 `references/pitfalls.md`。
4. **上传附件** — 上传合同原件。输入：合同文件路径；动作：走钉钉内嵌选文件面板选取并回写；易失败点：见 `references/pitfalls.md`。
5. **提交前核对** — 输出全字段清单给用户过目，**由用户点提交**。输入：已填字段；动作：逐项对照下方验证清单；易失败点：见 `references/pitfalls.md`。

## 失败与回退

- 草稿被覆盖：模板一份草稿只能存一条，填新单会覆盖旧草稿，覆盖前先存字段快照。
- 操作失焦：技术处置见 `himice-dingtalk-cua-toolkit` 与 `references/pitfalls.md`，本 skill 不重复。
- 填错已提交：**撤回需人工**，机器人不自动撤回，立即告知用户。
- 推送不可用：先跑 `dingtalk_health` 自检；webhook 未配置就**明说推不出去**，不假装发送成功、不编造发送记录。

## 提交前验证清单

逐项确认后才允许提交：

- [ ] 申请人 / 部门自动带出正确
- [ ] 申请人所在公司与所用公司印章一致
- [ ] 跨公司印章选择正确；若为「是」，电子章/实体章与是否需要原件**已问过用户**
- [ ] 文件管控分类与用户告知一致
- [ ] 用印文件名称 = 鱼鹰号 + 项目名称 + 上传文件名，且与附件文件名一致
- [ ] 文件接收单位是合同对方单位**全称**
- [ ] 合同金额与合同条款一致，且汉字大写自动生成结果正确
- [ ] 文件份数与实际上传份数一致
- [ ] 合同约定份数与上传份数不一致时，已向用户确认
- [ ] 印章类型、电子章/实体章、是否需要原件符合默认或用户指定
- [ ] 附件已上传成功且只有一份，文件名与大小正确
- [ ] 备注为空，或已按用户要求写明特殊情况

## 归档

按项目归档到 `用印流程-{鱼鹰号}-{项目名称}/`，内含 `合同原件/`、`提交凭证/`、`归档台账.md`。同一项目的多次用印放同一文件夹。台账每次用印一行，缺件写「xx 后补」。

**台账状态栏必须写清来源**：谁提交的、依据是用户告知还是截图。审批单截图或链接**向用户索取**，不得自行编造。
