# Himice 钉钉付款申请代填

通过桌面 GUI 自动化在**用户已登录的钉钉客户端**中代填审批表单。
本技能负责**填到提交前为止**，提交动作一律由人工确认后执行。

> 依赖共用工具包 `himice-dingtalk-cua-toolkit`（截图 / OCR / 点击 / 输入 / 窗口基准配置）。
> 本技能**不复制**工具包内的脚本，只引用；使用前先按工具包的 `config.env.example` 配好本机参数。

## 适用场景

- 用户提供合同 / 发票 / 结算单，要求发起一笔项目付款
- 常见付款性质：预付款、全款、尾款、押金
- 本技能只覆盖「项目类付款申请（厦门）」模板；其他模板的字段结构不同，不可照搬

## 前置条件

1. **工具包就绪**：`himice-dingtalk-cua-toolkit` 已安装，`config.env` 已按本机填写（钉钉窗口基准、Retina 倍率、TMP_DIR）
2. **系统权限**：辅助功能 + 屏幕录制均已授予 DSH 客户端（缺任一，截图或点击会静默失败）
3. **屏幕常亮**：开始前启动 `caffeinate`，否则锁屏后截图只拍到锁屏画面
4. **本机默认值**：复制 `references/field-mapping.example.md` 为 `field-mapping.local.md`，补全申请人、默认部门、默认操作/付款公司、默认负责人、鱼鹰号别名表等；**该文件已在 .gitignore 中，只存本机**
5. **凭证可读**：合同 / 发票 / 结算单已能被读取（扫描版 PDF 走 OCR）
6. **用户在场**：操作期间用户不能使用电脑，且每次交互前需重新聚焦钉钉窗口
7. **唯一草稿**：该模板**只保存一份未提交草稿**，填新单会覆盖旧草稿——覆盖前先按「失败与回退」里的快照法留档

## 逐步操作

### 1. 读凭证并核对金额（**先于一切界面操作**）

1. 逐份读取凭证：合同取总价与付款条件，发票取价税合计，结算单取实际结算额
2. 按 `references/business-rules.md` 判定本次应付金额：合同与发票不一致时**停下向发起人确认**，不得静默取其一
3. 确定付款性质（预付款 / 全款 / 尾款 / 押金）与成本费用类别组合
4. 按合同约定付款日倒推「约定付款时间」
5. 把核对结果回报发起人，等确认后再动界面

### 2. 打开表单

1. 聚焦钉钉窗口（工具包的 `focus`）
2. 左侧导航「工作台」→「OA审批」→「发起审批」标签
3. 点搜索框 → 输入审批单名称 → **点结果里正确的那一个**（同族模板会并排，见 pitfalls 通用坑）
4. 表单打开后会提示「已自动填写上次未发布草稿内容」——如需从空表开始，点右上角「清除内容」

### 3. 逐字段填写

按 `references/field-mapping.md` 的顺序填。要点：

- **自由文本字段**（备注、收款单位、开户行、账号、金额）用 Unicode 方式输入
- **选择 / 关联字段**（项目负责人、鱼鹰号、成本费用类别、抄送人）是拼音输入法式：打拼音 → 出候选 → 按数字键选字
- **日期字段**是两层浮层（截断处置见 `pitfalls.md` #8）
- 每填完一个字段**截图复核一次**，不要连续盲操作
- 底部字段被窗口底边挡住时先滚到屏幕中部再点（见 `pitfalls.md` #18）

### 4. 上传附件

按 `references/business-rules.md` 的「附件要件」确定该传哪几份。上传流程：

`+ 添加附件` → `选择本地文件上传` → 文件面板 `Cmd+Shift+G` → 输入完整路径 → 回车 → `打开` → 上传面板点`确定`

### 5. 设置抄送人

滚到表单最底部「抄送人」→ 点右侧 `+` → 在选择器顶部搜索框输姓名 → 点结果行 → 右侧显示「已选择（n/m）」→ 点窗口右下角`确定`。

### 6. 停机确认

填完后**不点提交**。整理字段清单回报发起人，由人工复核后自行提交。

## 字段映射

完整表见 `references/field-mapping.md`（字段名 / 必填 / 取值来源 / 控件类型 / 默认值来源 / 格式校验）。

## 失败与回退

本节只给**决策**（这一步出错该做什么）；**机制与细节一律在 `references/pitfalls.md`**，不在两处各写一份。

| 现象 | 处置 |
|---|---|
| 点击无反应、字段没变 | 先重新聚焦钉钉窗口再点一次。**九成是焦点被抢，不是坐标错**（`pitfalls.md` #1） |
| 拼音打进去了但没出候选 | 确认该字段的控件类型：不是联想控件就改 Unicode 直接输中文（`pitfalls.md` #5） |
| 数字键选字后字段变成乱码 | 清空重来，用逐个退格而非 `Cmd+A`（`pitfalls.md` #6） |
| 日期日历选不到具体某天 | 见 `pitfalls.md` #8 |
| 附件上传面板内一片空白 | 见 `pitfalls.md` #9 |
| 误触附件预览弹出 WPS | 见 `pitfalls.md` #11 |
| 表单被误关 / 滚出界 | 点左侧该表单标签页切回；标签页没了就重新从模板入口打开 |
| 需要清空表单重填 | 先确认草稿可丢弃，**可丢弃前先把字段值写成快照文件**（本地，不入库），再「清除内容」（`pitfalls.md` #15） |

**覆盖草稿前必须留快照**：该模板只有一份草稿，快照至少记录——鱼鹰号、成本费用类别、备注、约定付款时间、DC、付款金额、收款单位、开户行、账号、电话、附件文件名。

## 提交前验证清单

逐项核对，全部通过才交人工提交。**加粗项在 `references/business-rules.md` 中有对应硬规则，不得跳过。**

- [ ] **付款金额与发票价税合计一致**；与合同金额不一致处已向发起人确认并留痕（R4）
- [ ] **大写金额与付款金额互相印证**（大写由表单自动生成，可反查金额是否真的填进去了）（R5）
- [ ] **收款单位与发票开票方一致**；若为关联方代收，已取得发起人明确指示并写入备注（R7）
- [ ] 开户行、账号与合同/发票所载一致，且**账号为纯数字、已核对位数**（R6）
- [ ] 项目名称（鱼鹰号）为完整串，未被输入框吞字符
- [ ] 成本费用类别为 **A 类 + B 类** 组合，且与本次付款性质匹配（R11）
- [ ] **约定付款时间已按合同约定日倒推，并预留 2 天以上**（R8）；合同期限已过时已写明顺延原因（R10）
- [ ] 合同约定的付款期限已写入备注（R9）
- [ ] **附件要件符合本笔付款性质**（预付款：发票 + 合同；尾款/结算：发票 + 合同 + 结算单）（R2）
- [ ] **备注只写凭证缺件与必要口径说明**（R1、R3），未写「项目预算表后补」，未越界写其他流程材料
- [ ] DC 付款为「否」（除非发起人另有说明）（R12）
- [ ] 付款通知电话为发起人钉钉预留号（R13）
- [ ] 抄送人完整：含项目要求的固定抄送人（R14），且未擅自扩大抄送范围（R15）
- [ ] 表单已自动保存（标题栏出现「已保存」与时间）
- [ ] **未点击提交**
