# 字段映射表 · 项目类付款申请（厦门）

适用范围：钉钉 OA 审批模板「**项目类付款申请（厦门）**」
本表只描述**字段本身**：是什么、必填否、值从哪来、用什么控件填、格式怎么校验。
「怎么点会失败、怎么救」在 `pitfalls.md`；「业务硬规则」在 `business-rules.md`。

> 示例值一律为占位符（`<收款单位>`、`<鱼鹰号>`、`<金额>`）。
> 本机实际默认值来自 `field-mapping.local.md`，**不写入本文件**。

## 通用说明

- **控件类型 → 操作手法**（只读 / 自由文本 / 拼音联想 / 下拉单选 / 日期浮层 / 附件 / 人员选择器）
  统一见工具包 `../../himice-dingtalk-cua-toolkit/references/control-types.md`，本文件不重复解释。
- 下表的「控件类型」列使用该文件的标准叫法，读者可直接对上操作手法。
- 字段顺序即表单自上而下的排列顺序；表单很长，底部字段需先滚动到屏幕中部再操作（见通用坑 E4）。

## 取值优先级

同一字段有多个来源时，按下列顺序取值，冲突时**停下确认**而不是自行择一：

1. 发票所载（金额、销方、开户行、账号）
2. 合同所载（付款条件、总额、乙方账户）
3. 结算单所载（实际结算额）
4. 本机默认值（`field-mapping.local.md`）
5. 发起人当次口头说明（须落进备注或快照留痕）

## 相邻模板辨析

「项目类付款申请（厦门）」与「非项目类付款申请单」名称相近、搜索结果里**并排出现**，字段结构完全不同，点错会填错整张表。
选定前先核对模板全名与括号内的公司限定。
