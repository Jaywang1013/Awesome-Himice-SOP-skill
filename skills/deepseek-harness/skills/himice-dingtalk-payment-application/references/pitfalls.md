# 踩坑记录 · 钉钉审批代填

组织方式：**症状 → 原因 → 处置**，不按字段组织。
分两节：**通用跨模板**（换任何模板都成立）与**付款申请专属**。

> 团队规范：**具体屏幕坐标不进文档**。坐标随窗口位置、钉钉版本变化，一律靠"先 look 再 click"现取现用；
> 窗口基准（位置 / 尺寸 / Retina 倍率）作为可配置项放在工具包 `config.env`，不在本文件写死。

## 一、通用跨模板

### 1. 点击完全没反应

- **症状**：点了输入框，光标不进；点了按钮，面板不弹；一切像"卡住了"
- **原因**：**焦点被其他窗口抢走**——DSH 自己的窗口会反复置顶，绝大多数"点击失效"是这一条
- **处置**：先重新聚焦钉钉窗口，再点一次。**不要先去调坐标**，坐标错的概率远低于焦点错

### 2. 区域截图报 `could not create image from rect`

- **症状**：带区域的 `screencapture` 必然失败，全屏截图却正常
- **原因**：部分 macOS 版本上区域截图行为异常
- **处置**：改为**全屏截图 + 裁切**（工具包 `look*.sh` 已按此实现）

### 3. 截图内容不对——拍到的是锁屏或别的窗口

- **症状**：OCR 只识别到时间、日期，或认出的是攻略/聊天内容
- **原因**：屏幕已锁定，或前置了错误的窗口
- **处置**：开工前先 `caffeinate` 保持常亮；每次截图前确认目标窗口在最前

### 4. 无障碍（AX）读不到任何字段

- **症状**：能列出窗口，但拿不到输入框和文字
- **原因**：钉钉是 Qt 自绘客户端，控件树几乎为空壳
- **处置**：**放弃 AX，一律走截图 + OCR**。AX 只用来置顶窗口

### 5. 直接打中文进不去字段

- **症状**：想输"某某公司"，字段毫无反应或出现拼音字母
- **原因**：该字段是**拼音输入法式**控件（见 `field-mapping.md` 控件类型列）
- **处置**：打拼音 → 出现候选 → 按数字键选字

### 6. 数字键选字偶尔输成了字面文本

- **症状**：字段里出现 `xxx2` 这种拼音+数字的乱码
- **原因**：候选还没弹出就按了数字键，或候选时序不稳
- **处置**：**每次选字后立刻复核字段值**；出问题就清空重来，清空用逐个退格（`Cmd+A` 在本表单有副作用）

### 7. 找不到"确定"按钮

- **症状**：面板里选好了，却找不到提交按钮
- **原因**：**确定/取消在窗口右下角**，不在浮层内部
- **处置**：取消在左、确定在右，位置固定在窗口右下区域

### 8. 日期日历选不到具体某天

- **症状**：日历只露出标题行和零星几个日期，其余被窗口底边切掉
- **原因**：日历是**第二层浮层**，不会自动上移
- **处置**：**把光标移到日历外面再滚动**，浮层随表单整体上移；日历外滚动才有效，在日历内滚动无效

### 9. 附件上传面板里一片空白

- **症状**：点「打开」后面板弹出，但里面看不到任何文件条目
- **原因**：**属正常渲染**，不是上传失败
- **处置**：直接点面板右下角`确定`。**不要因为看不见就重复上传**——会产生重复附件

### 10. 附件名字不对 / 上传后文件名变了

- **症状**：附件区显示的不是原始文件名
- **原因**：钉钉取的是**文件名**而非完整路径；若用了改名副本就会显示改名后的名字
- **处置**：用短路径副本可以，但**必须保留原始文件名**。含全角 `【】（）` 的中文路径可正常上传，不必为符号改名

### 11. 误触附件预览，弹出 WPS

- **症状**：想删附件却弹出了预览窗口
- **原因**：附件行的「预览 / 删除」**共用同一行 y，仅靠 x 区分**；用错上一行的 y 就会命中预览
- **处置**：`Cmd+W` 关闭预览（`Esc` 无效）；悬停后先确认按钮 y 与目标文件行对齐

### 12. 模板搜索点错，打开的不是要的模板

- **症状**：填了几个字段才发现结构对不上
- **原因**：搜索结果**横向排列**，同族模板并排（如搜"借款"会返回多个相似名）
- **处置**：点之前先核对模板全名；发现进错模板立即退出，不要将错就错

### 13. 模板搜索框点了不聚焦

- **症状**：占位提示文字没消失，输入的字符没进去
- **原因**：点在了搜索框可点区域之外
- **处置**：改点文本框内靠左的位置；若仍无效，换位置重试并确认焦点

### 14. 金额输入不了小数点

- **症状**：金额字段只能输整数
- **原因**：用"真实键码"方式输入时，键码表里**没有小数点**
- **处置**：**金额字段一律用 Unicode 方式输入**（中文、小数点、全角符号均正常）

### 15. 填新单时旧草稿不见了

- **症状**：打开表单发现上次填的内容没了（或反过来，旧内容串进新单）
- **原因**：一个模板**只保存一份未提交草稿**，重新打开会自动载入，填新单会覆盖
- **处置**：覆盖前先把旧草稿字段写成**本地快照文件**（不入库）；确认可丢弃后再清空

### 16. 「清除内容」点了却没清干净

- **症状**：清空后仍有字段残留旧值（实测"项目负责人"会残留）
- **原因**：清除不覆盖全部字段
- **处置**：清除后**逐字段复核一遍**，残留项手工改掉

### 17. 表单滚不动

- **症状**：滚轮转了但表单位置不变
- **原因**：光标不在表单区域内
- **处置**：把光标移到**表单区域内**再滚动

### 18. 底部字段点不到

- **症状**：字段就在眼前但点击无效
- **原因**：字段贴近窗口底边，点击区域被裁掉
- **处置**：**先把该字段滚到屏幕中部再点**

### 19. 「+ 添加附件」点文字右端不弹面板

- **症状**：点了按钮，什么都不发生，也没有报错
- **原因**：按钮可点区域从文字**左侧**开始，点文字右端会落在框外
- **处置**：按 OCR 给的位置直接点，不要凭"文字更宽"往右加偏移

### 20. 面板挡住了要点的字段

- **症状**：下拉/选择器展开后，把下方的目标字段盖住
- **原因**：浮层向下展开
- **处置**：先关掉浮层（或滚动让目标字段离开浮层区域）再操作

## 二、付款申请专属

### 21. 鱼鹰号输入被吞字符

- **症状**：填完复核，发现中间的空格没了（如 `编号全称` 黏在一起）
- **原因**：输入框对空格的保留不稳定
- **处置**：**以编号本身正确为准**；填完必须复核一次，必要时用别名表里的无空格写法

### 22. 不清楚成本费用类别该填什么

- **症状**：只知道"这是付款"，不知道类别怎么组合
- **原因**：该类别的值是 **A 类（费用性质）+ B 类（付款性质）写在同一个框**
- **处置**：先定性质（搭建/设计/酒店/场地/第三方等）再定性质（预付款/押金/尾款/全款），拼成一个值；两者缺一会被打回

### 23. 金额明明填了，却是错的

- **症状**：金额字段看着有值，但金额不对
- **原因**：数字键输入或解析偏差
- **处置**：**用大写做反查**——大写由表单自动生成，大写与预期不符说明金额没真正填对

### 24. 抄送人加不进去

- **症状**：点 `+` 后面板里搜不到人
- **原因**：选择器**默认作用域是本部门**，跨部门人员搜不到
- **处置**：先把面板顶部的组织范围切到公司级，再搜姓名

### 25. 附件要件传错

- **症状**：被财务打回"缺件"
- **原因**：不同付款性质的附件要件不同
- **处置**：按 `business-rules.md` 的「附件要件」确定；预付款与尾款/结算的要件**不一样**

### 26. 备注写了不该写的

- **症状**：备注里出现"项目预算表后补"之类
- **原因**：把**另一条流程**的材料误当成付款要件
- **处置**：备注只写三大件实际缺的 + 必要口径说明；材料归属见 `business-rules.md`
