# 招投标分析规则（Tender Rules）

本文件提供招投标分析与策略制定的领域规则，供 `himice-tender-simulation` 评标与方案阶段参考。默认值只填补缺失信息，招标书明确条款优先。

## 1. 招标书拆解清单

| 类别 | 提取内容 | 关注点 |
| --- | --- | --- |
| 资格 | 注册资金、资质、业绩、人员、社保、纳税 | 硬性门槛，缺一项即废标 |
| 商务 | 付款方式、保证金、工期、违约责任、本地化、开票 | 付款周期影响现金流；保证金比例影响资金占用 |
| 技术/服务 | 交付物清单、服务标准、人员配置、应急预案 | 评分权重最高部分，逐条对应 |
| 评分 | 评分项、满分、权重、加分项、扣分项、废标项 | 一切策略围绕评分表展开 |
| 时间线 | 澄清截止、投标截止、开标、结果公示 | 反推内部准备时间 |

## 2. 评分对标法

- 把招标书评分表转成行：`评分项 | 满分 | 我方可得分 | 缺口 | 如何补`。
- 权重 >10% 的评分项优先投入；先保权重分，再抢加分项。
- 逐项写"可得分依据"：必须落到可证明的材料（案例合同、人员证书、方案细节），不写空话。

## 3. 报价策略参考

| 策略 | 适用 | 注意 |
| --- | --- | --- |
| 低价冲量 | 竞争激烈、技术分接近、我方想保中标 | 核验毛利，避免亏本中标 |
| 均衡报价 | 评分中报价占比较低（如 10-20%） | 不必最低，拿合理分即可 |
| 高价高质 | 技术/服务分占比高、客户重品牌 | 用方案和案例支撑溢价 |
| 阶梯/组合报价 | 可选配置、分项报价 | 主方案保分，选配拉利润 |

- 报价前先用 `himice-budget-process` 按供应商成本测算毛利，报价不得低于成本红线。
- 报价得分规则以招标书为准（最低价满分/平均价满分等）；缺失时用"最低价基准"并标注。

## 4. 废标与高风险清单（逐项检查）

- 未按时缴纳/错误缴纳保证金
- 资质证书过期、经营范围不符
- 业绩合同金额/类型不满足要求
- 法定代表人/被授权人身份证明缺失
- 投标文件未盖章、未签字、密封/格式不符
- 报价超过最高限价或低于成本价（如规则禁止）
- 关键条款负偏离（工期、付款、质保）
- 存在围标串标嫌疑（与其他投标人异常一致）

## 5. 需澄清与询价建议

- 招标书矛盾处、参数不明确、评分规则歧义 → 列入"需澄清"清单，在澄清截止前向招标方提出。
- 澄清时间、对象、形式以招标书为准。

## 6. 资料边界

- 招标书、报价、资质属于未公开资料，只在已授权范围内处理，不发送到未授权服务。
- 模拟推演中的竞争对手信息均为推断，不得作为真实情报使用或传播。
