# Himice 预估协作人审批表（备用金申请表）规则

## 字段映射

| 审批表字段 | 预算表来源 | 规则 |
| --- | --- | --- |
| 鱼鹰项目名称（含编号） | 会议名称 | 原样填写 |
| 报账人 | 会议报账人 | 缺失写 `[待确认]` |
| 营业额（估） | 预计收入总计 | 使用数值，显示两位小数 |
| 毛利率（估） | 预计毛利率 | 使用数值，显示 `0.00%` |
| 毛利润（估） | 营业额 × 毛利率 | 使用公式，不手填结果 |
| 活动开始/结束 | 日程安排 | 使用真实日期 |
| 活动内容 | 会议名称去除项目编号后的主题 | 无法分离时保留会议名称 |
| 活动地点 | 预算表明确地点或项目名称中明确的城市 | 不能确认时 `[待确认]` |
| 活动人数 | 会议人数 | 使用整数 |
| 客户名称、纳税人识别号 | 用户明确提供 | 仅本地输入与输出 |

## 部门默认信息与优先级

每次调用必须先完成三选一确认。默认信息只读取本机 `department-defaults.local.md`；仓库中的 `department-defaults.example.md` 仅提供格式和厦门公司项目二部的非个人默认项。

| 字段 | 确认后来源 | 优先级 |
| --- | --- | --- |
| 活动类型、业务类型、是否竞标、是否为本地客户、客户来源、客户类型 | 本地默认信息或本次修改 | 本次修改 > 本地默认 > `[待确认]` |
| 客户联系人、销售/谈判/执行人及比例 | 本地默认信息或本次修改 | 本次修改 > 本地默认 > `[待确认]`；严禁提交个人资料 |
| 第二客户信息 | 用户或预算表明确来源 | 无来源时空白或 `[待确认]` |
| 活动日期、内容、地点、人数、营业额、毛利率、毛利润、报账人 | 项目预算表 | 预算表为准 |

除已确认的本地默认信息或用户本次修改外，不得猜测任何字段；不得沿用模板示例姓名、比例或联系方式。

## 隐私与交付

- 禁止将客户名称、纳税人识别号和联系人上传云端、网页、API、云盘或 GitHub。
- `department-defaults.local.md` 可能包含客户和员工个人信息，必须只保存在本机且已由 `.gitignore` 排除；禁止在提交记录、Skill 文档、测试数据和日志中保存真实客户资料。
- 仅将空白模板保存到 `assets/`；完成表只保存给用户的本地输出目录。
