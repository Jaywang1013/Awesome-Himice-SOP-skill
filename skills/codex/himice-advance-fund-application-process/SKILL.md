# Himice Advance Fund Application Process

先读取 [预估协作人审批表规则](references/advance-fund-rules.md)。默认使用 `assets/【预估协作人审批表模板】鱼鹰号+活动名称.xlsx`。本 Skill 只生成表格，不替代审批、付款或税务判断。

## 本地数据边界

- 客户名称、纳税人识别号、联系人、个人姓名及原始预算表只能在用户本机处理和保存。
- 不得通过网页、API、云盘、外部服务或 GitHub 上传这些资料；不得将真实客户资料写入 Skill、README、测试样例、提交信息或日志。
- GitHub 中仅可保存空白模板、通用规则和不含真实客户信息的脚本/说明。输出文件保存到本地 `outputs/`。

## 强制默认信息确认

在读取预算表或修改审批表前，先检查同目录 `references/department-defaults.local.md`；没有该文件时，提示用户从 `references/department-defaults.example.md` 复制并仅在本地补全。每次调用都必须先向用户展示以下确认，不得跳过：

> 这是 `<部门>` 的默认信息。是否使用该默认信息？若有修改请修改后提交给我；若想更改默认信息，请按格式修改。
>
> 1. 使用默认信息，继续执行
> 2. 有修改，根据用户给到的信息继续执行
> 3. 更改默认信息，按用户给到的新默认信息执行并更改本地默认信息

- 选择 1：使用本地文件中已完整配置的默认字段；其他字段仍从预算表提取。
- 选择 2：以本地默认值为底稿，并以用户本次提供的字段覆盖；不修改本地文件。
- 选择 3：先校验用户按示例格式提供的完整默认信息，再仅覆盖本机 `department-defaults.local.md`，同时以新部门信息完成本次表格。不得把个人信息写回 Skill 或 GitHub。

选项确认前不得开始填表；本地配置缺失或含 `<仅在本地填写>` 占位符时，不能选择 1，应要求用户补全或选择 2。默认字段及其优先级见参考规则。

## 输入与提取

收集项目预算表、客户名称、纳税人识别号；优先从预算表提取会议名称、会议报账人、日程、会议人数、预计收入总计、预计毛利率和预计毛利。客户名称、税号或报账人缺失时标 `[待确认]`，不要使用模板示例值代替。

## 填写流程

1. 只编辑审批表的第 4 行；保留工作表、列、颜色、格式、下拉选项和备注。
2. 写入：项目名称、报账人、预计营业额、预计毛利率；毛利润用 `营业额×毛利率` 公式生成。金额保留两位小数，毛利率显示两位百分比。
3. 从日程填写活动开始/结束、从预算填写会议人数；可直接从项目名称或预算字段确认的活动内容与城市也可填写。活动类型、业务类型、竞标状态、本地客户、客户联系人、客户来源、客户类型及销售/谈判/执行比例按已确认的本地默认信息或本次修改填写；其余无法确认的字段保持空白或标 `[待确认]`，不保留模板示例数据。
4. 写入客户名称和纳税人识别号；它们仅存在于本地输入/输出工作簿，绝不写入仓库或云端。
5. 核验营业额、毛利率、毛利润与预算表一致；扫描目标表公式错误并渲染检查格式。预算表其他工作表即使存在历史公式错误也不得修复。

## 交付

交付本地生成的审批表，并简述已填字段和待确认字段。不要在交付说明中复述客户名称、税号或其他敏感客户资料。
