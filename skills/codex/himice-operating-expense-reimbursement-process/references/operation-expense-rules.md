# Himice 操作费用报销：单表录入规则

## 模板与填写边界

- 默认模板为 `assets/【模板】项目操作收支明细表.xlsx`，当前仅含 `表1 (2)` 一张工作表；该表显示为“项目操作收支明细表”。
- 只填写现有付款区和空白明细行；保留数据验证、金额格式、行/列格式、小计和资金汇总公式。不得创建、删除、移动或重排工作表。
- 每行填写：序号、日期、类型、明细、摘要、单价、数量、次数、金额公式、发票、备注、经手人。金额固定为 `单价×数量×次数`，不得覆盖小计或资金合计。
- 支付截图可作为付款事实；只有实际发票文件时才在“发票”列选择 `√`。没有发票时留空。

## 票据、行程单与路线

- 发票、支付凭证与行程单属于同一交易的佐证时，不得重复金额。
- 行程单有 N 笔行程时，必须生成 N 行；每行使用该行程自己的日期和金额，并核对 N 行金额之和等于关联发票的价税合计。
- 备注写法固定：`滴滴：<出发地>-<目的地>`、`货拉拉：<出发地>-<目的地>`、或 `<平台>：<出发地>-<目的地>`。
- 发票覆盖多笔行程时，每一条受该发票覆盖的行程都勾选 `√`；不能因共用同一张发票而合并行程或漏勾。

## 付款路径与费用映射

- 现金支出：微信/支付宝/零钱、项目备用金或个人垫付且有支付凭证。
- 刷卡支出：可确认的信用卡/银行卡刷卡。
- 已转帐款项：有银行转账证据的已付支出。
- 未付款：明确尚未支付的应付款。路径不清楚则标 `[待确认]`，不可猜测。
- 交通（客运、货运、机票、动车、加油）→ `操作费用/交通费`；餐食 → `操作费用/餐饮费`；印刷、花卉等 → `操作费用/物料费`；用途不充分的便利店等 → `操作费用/其他操作费`。
- 酒店、会场、餐饮、机票、动车等会议服务商代付或酒店签单，不自动纳入个人操作费用报销。

## 已确认的预算/差异核对标准

| 项目 | 标准 | 核对方式 |
| --- | ---: | --- |
| 餐饮费 | ¥70/人/天 | 公司参与人数 × 执行天数 |
| 交通费 | ¥1,000/人 | 公司参与人数 × 次数 2 |
| 住宿费 | ¥300/间/晚 | 向上取整（公司参与人数÷2）× 住宿晚数 |
| 正式员工人补 | ¥120/人/天 | 正式员工人数 × 执行天数 |
| 试用期/实习生人补 | ¥70/人/天 | 对应人数 × 执行天数 |
| M 级管理层人补 | ¥0 | 不计人补 |

B1–B6 为项目助理、项目专员。上述标准不是未经确认的报销上限；审批链、税务、报销时限、账户与超标准处理均为 `[待财务确认]`。
