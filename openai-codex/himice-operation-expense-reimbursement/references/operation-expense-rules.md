# Himice 操作费用报销：已确认规则与边界

## 已确认的操作费用标准

| 项目 | 标准 | 预算/差异核对方式 |
| --- | ---: | --- |
| 餐饮费 | ¥70/人/天 | 公司参与人数 × 执行天数 |
| 交通费 | ¥1,000/人 | 公司参与人数 × 次数 2 |
| 住宿费 | ¥300/间/晚 | 向上取整（公司参与人数÷2）× 住宿晚数 |
| 正式员工人补 | ¥120/人/天 | 正式员工人数 × 执行天数 |
| 试用期/实习生人补 | ¥70/人/天 | 对应人数 × 执行天数 |
| M 级管理层人补 | ¥0 | 不计人补 |

B1–B6 为项目助理、项目专员。

## 报销整理边界

- 上表是本对话已确认的操作费用预算和差异核对标准；除非公司财务制度或已确认项目文件另有说明，不能将其表述为报销审批上限。
- 实际报销以真实发生金额和有效凭证为基础；预算金额、黄色现金标记、客户报价或代付服务费均不是个人报销凭证。
- 同一实际支出不得同时出现在个人报销、供应商付款和会议服务商代付中。资料不完整或付款路径不清楚时标记待确认。
- 审批流程、凭证/发票类型、税务处理、时限、账户和超标准审批规则尚未在本 SOP 中确认，必须由财务补充。
