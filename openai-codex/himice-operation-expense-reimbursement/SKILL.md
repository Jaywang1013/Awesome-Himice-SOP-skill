# Himice Operation Expense Reimbursement

先读取 [操作费用报销规则](references/operation-expense-rules.md)。本 Skill 用于整理报销资料和预算差异，不替代财务审批、税务判断或付款操作。

## 开始前收集

一次性确认或标记缺项：项目/会议名称、对应已确认预算表、报销人、报账人、会议负责人、每笔实际支出（日期、类别、金额、用途、支付人）、可用的发票/收据/支付凭证、实际公司参与人数、执行天数、住宿晚数及人员结构。

没有公司报销单模板时，只输出可复核的报销明细、预算差异和待补资料清单；不要凭空生成或提交财务审批单。

## 整理与核对

1. 将每笔实际支出映射到批准预算的对应项目；记录预算金额、实际金额、差异金额、差异原因和资料状态。一个支出只能保留一个付款/报销路径，防止与供应商付款、会议服务商代付或其他报销重复计入。
2. 餐饮、交通、住宿、正式员工人补、试用期/实习生人补按参考规则计算基准并与实际支出比较。标准是当前已确认的预算/差异核对依据；未经财务制度或项目审批确认，不得把它们宣称为报销上限或审批结论。
3. M 级管理层人补为 0；B1–B6 为项目助理/项目专员。人员身份、人数、天数或住宿晚数不清楚时标为 `[待确认]`，不猜测金额。
4. 酒店会场、住宿、餐饮、机票、动车等会议服务商代付项目属于项目预算的专用代付结构，不会因为出现在预算中就自动成为个人操作费用报销。茶歇不进入代付服务费基数。
5. 预算表中黄色仅代表预计成本需要提取现金的物料总价，不能自动视为已发生支出、可报销金额或现金报销依据。

## 交付与验收

交付报销明细时，至少包含：费用类别、发生日期、用途、实际金额、预算对应项/预算金额、差异、支付/报销人、凭证状态、待确认项。总额必须等于明细汇总，且不得改变原始凭证金额。

把以下内容单列为 `[待财务确认]`，不要擅自补充：审批链、发票抬头/税务处理、可报销凭证口径、报销时限、付款账户、报销单字段和超标准处理方式。
