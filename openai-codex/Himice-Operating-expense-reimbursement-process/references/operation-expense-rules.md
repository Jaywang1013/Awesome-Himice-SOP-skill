# Himice 操作费用报销：已确认规则、结算表录入与边界

## 结算表固定边界

- 默认仅修改 `结算-项目收支明细` 工作表；`项目预算表-项目决算表`、`项目清算表`、`人员补助表` 不得写入、删除、移动或修复。
- 收入、现金、刷卡支出、已转账款项和未付款款项是独立付款路径。只有凭证、支付证明或用户明确说明支持时才可选择路径；不明确时标 `[待确认]`。
- 每条实际支出应填：序号、票面日期、类型、明细、摘要、单价、数量、次数、金额公式、发票勾选、备注、经手人。金额用 `单价×数量×次数` 计算，不能覆盖小计/资金合计公式。
- 发票、行程单和支付记录互为同一交易佐证时，只计一次。文件名金额与票面价税合计冲突时，以票面价税合计入账并保留备注。
- 常用映射：加油/机票/动车等为 `操作费用/交通费`；餐食为 `操作费用/餐饮费`；印刷/花卉等为 `操作费用/物料费`；配送等服务为 `操作费用/其他操作费`；已确认酒店签单或酒店代付为 `签单/酒店`。个人垫付住宿需先确认路径，再使用 `操作费用/住宿费` 或 `签单/酒店`。

## 已确认的操作费用标准

| 项目 | 标准 | 预算/差异核对方式 |
| --- | ---: | --- |
| 餐饮费 | ¥70/人/天 | 公司参与人数 × 执行天数 |
| 交通费 | ¥1,000/人 | 公司参与人数 × 次数 2 |
| 住宿费 | ¥300/间/晚 | 向上取整（公司参与人数÷2）× 住宿晚数 |
| 正式员工人补 | ¥120/人/天 | 正式员工人数 × 执行天数 |
| 试用期/实习生人补 | ¥70/人/天 | 对应人数 × 执行天数 |
| M 级管理层人补 | ¥0 | 不计人补 |

B1–B6 为项目助理、项目专员。

## 报销整理边界

- 上表是已确认的操作费用预算和差异核对标准；没有财务制度或项目书面确认时，不是报销审批上限。
- 实际报销以真实发生金额和有效凭证为基础。预算金额、黄色现金标记、客户报价和代付服务费都不是个人报销凭证。
- 同一支出不能同时出现在个人报销、供应商付款和会议服务商代付中；资料或付款路径不清楚时标记 `[待确认]`。
- 审批流程、凭证/发票类型、税务处理、时限、账户和超标准审批规则尚待财务补充。
